Demand Generation
สร้างดีมานด์ — การตลาด, CRM, เสนอราคา, ปิดการขาย
1
4 โหมดการขาย (Product Concepts)
หินก้อนนำเข้า / แผ่นสำเร็จรูป / ตัดตามสั่ง / งานโครงการ BOQ — พร้อมตัวอย่างจริงและกำไรจริงรายโครงการ
→
2
ติดต่อลูกค้าและ CRM
ฟอร์มหน้าเว็บ → Opportunity เข้า Pipeline อัตโนมัติ → Contact สร้าง/เชื่อมให้เอง — ไม่ต้องพิมพ์ข้อมูลซ้ำ
→
BOQ Estimation — ตั้งแต่เตรียมระบบ ปิดการขาย จนถึงส่งมอบ
B1
BOQ Estimation + Sold-as-Project (ฉบับเต็ม)
Rate Library → BOQ Document → ใบเสนอราคา → ผูกสินค้าจริง → Project + Gantt + วางบิลเป็นงวด → ดูกำไรจริง
→
B2
สำหรับทีมขายมือใหม่ (Quickstart)
สมมติว่า Rate Library มีคนเตรียมไว้ให้หมดแล้ว — เหลือแค่ 3 ขั้นตอนที่ sale ต้องทำจริง จนถึงพิมพ์/ส่งออกให้ลูกค้า
→
B3
สำหรับทีม Operation (หลังลูกค้าตกลงซื้อ)
เลือกแผ่นจริง → Recompute Price → ส่งของ → ออกใบแจ้งหนี้ — งานต่อจากที่ทีมขายส่งมอบมา
→
B4
เตรียมระบบให้ทีมขายใช้งานได้ (สำหรับ Estimate)
ตั้ง Rate Library → ผูก Product → ทดสอบก่อนปล่อยใช้จริง — สิ่งที่ต้องทำก่อนทีมขายจะเริ่มใช้ deck Quickstart ได้
→
B5
ตัวอย่าง BOQ 5 แบบ
ตัวอย่างใบเสนอราคาจริงจากงานหน้างานประเภทต่างๆ
→
