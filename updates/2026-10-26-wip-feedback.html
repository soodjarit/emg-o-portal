[01] BOQ และใบเสนอราคา

ข้อประเด็นที่แจ้งผลการวิเคราะห์สถานะ
1.1ตั้งค่า Rate Library สำหรับงานที่มีหลายรูปแบบ (10+ แบบ) ซับซ้อนและไม่ยืดหยุ่นไม่ให้ผู้ใช้ตั้ง Rate Library เอง ระบบสร้างรายการให้เองจากไฟล์ Excel ที่ Import เข้ามา ผู้ใช้ไม่ต้องเข้าไปสร้างหรือกรอกก่อน
  • ราคามาจากไฟล์ Excel (แยกวัสดุ / ค่าแรง)
  • ต้นทุนดึงจากสินค้าในระบบ
  • รายการบริการที่ยังไม่มี ระบบสร้างให้และจำไว้ใช้ครั้งต่อไป
วิเคราะห์แล้ว · รอลูกค้ายืนยัน
1.2ต้องการนำข้อมูลจาก Excel เข้าใบเสนอราคา / BOQ โดยตรง โดยระบุกว้าง × ยาว × หนาImport จาก Excel เข้า BOQ ไม่ต้องกรอกเอง แล้วสร้างใบเสนอราคาจาก BOQ (ดูข้อ 1.6) ไฟล์ใช้รูปแบบใกล้เคียงใบเสนอราคาที่ลูกค้าใช้ มีโซน/JOB, รายการ, ชื่อหิน, ผิว, หนา, กว้าง, ยาว, จำนวน, หน่วย, ราคาวัสดุ/หน่วย, ราคาค่าแรง/หน่วย และ Overhead ที่หัวไฟล์
ระบบตรวจทีละขั้น ไม่ครบไม่ไปต่อ:
  1. ตรวจโครงสร้างไฟล์ (คอลัมน์ หน่วย ตัวเลข)
  2. ตรวจรายการ: บรรทัดหินต้องจับคู่สินค้าได้ก่อนไปต่อ บรรทัดบริการที่ยังไม่มี กดสร้างได้ในหน้าเดียวกัน
  3. ดูตัวอย่างยอดวัสดุ ค่าแรง Overhead
  4. ยืนยัน ระบบสร้าง BOQ ให้ตรวจ แล้วกด "สร้างใบเสนอราคา" (วัสดุและค่าแรง)
วิเคราะห์แล้ว · รอลูกค้ายืนยัน
1.3ความหนาของงานคือข้อมูลที่โรงงานต้องใช้ ไม่ใช่แค่หมายเหตุ—รอวิเคราะห์
1.4หา Project Code ในใบเสนอราคาไม่เจอ (อยู่ในแท็บ Other Info)—รอวิเคราะห์
1.5Overhead มีหลายอัตรา (5%, 10%, 15%, 20%) ไม่ใช่อัตราเดียว—รอวิเคราะห์
1.6ถามว่า Import เข้าใบเสนอราคา (QT) ตรงๆ ได้ไหม ทำไมต้องมี BOQควรมี BOQ และผู้ใช้ควรเห็นงานก่อนออกใบเสนอราคา ไม่ซ่อนไว้เบื้องหลัง ขั้นตอนที่เสนอ:
  1. Import ไฟล์ Excel ผ่านการตรวจทีละขั้น (ข้อ 1.2) ระบบสร้าง BOQ ให้ตรวจ
  2. ตรวจ BOQ บนหน้าจอ แก้ไขได้ถ้าจำเป็น
  3. กด "สร้างใบเสนอราคา" ขั้นตอนเดียว (มีปุ่มนี้อยู่แล้ว)
จึงเพิ่มแค่การ Import เข้า BOQ ส่วนจาก BOQ ไปใบเสนอราคาใช้ของเดิม
เหตุผลที่ต้องมี BOQ (รายละเอียดในหัวข้อ [04]):
  1. แยกใบวัสดุ / ใบค่าแรง
  2. สรุปท้ายใบ
  3. Cut List ที่มาทีหลัง
  4. เทียบยอดที่เสนอกับยอดจริง
  5. ตารางงานโครงการ

[02] การผลิต (MO) และคลังสินค้า

ข้อประเด็นที่แจ้งผลการวิเคราะห์สถานะ
2.1สร้างไอเทม Block ใหม่ใน PO แล้วระบบไม่คำนวณปริมาณ / ต้นทุน CBM ให้อัตโนมัติ—รอวิเคราะห์
2.2ใน MO ของงานตัด FG รายการวัตถุดิบแสดงเลข Slab ปนมาด้วย—รอวิเคราะห์
2.3กรอกขนาด Slab ทีละแผ่น (30–80 แผ่นต่อล็อต) เป็นงานหนัก—รอวิเคราะห์
2.4แก้ขนาดใน Excel แล้วต้องใส่กลับเข้าระบบ—รอวิเคราะห์
2.5ต้องการคอลัมน์ลำดับเลข Slab เพื่อตรวจสอบและติดตาม—รอวิเคราะห์
2.6ทำ MO ที่ตัดสต็อกแล้ว สินค้าที่ผลิตไม่เข้าคลัง—รอวิเคราะห์

[03] การแสดงผลและการใช้งาน

ข้อประเด็นที่แจ้งผลการวิเคราะห์สถานะ
3.1ค่ากว้าง × ยาวของ FG ไม่แสดงในคอลัมน์หลักของรายการสินค้า—รอวิเคราะห์
3.2ความหนาของ FG ต้องส่งต่อถึงใบสั่งผลิตให้ถูกต้อง—รอวิเคราะห์
3.3การแสดงสถานะสินค้า On Hold (หัวข้อที่หารือในที่ประชุม)—รอวิเคราะห์
3.4หน้ารายการสินค้าในใบเสนอราคา (Order Line) ดูไม่เหมือนเดิมและใช้งานยากขึ้น—รอวิเคราะห์

[04] ทำไมต้องมี BOQ (หน้าที่ของ BOQ ในระบบ)

ประกอบข้อ 1.6 — เหตุผลที่ Import เข้า BOQ ก่อน แล้วค่อยสร้างใบเสนอราคา

ข้อหน้าที่ของ BOQทำอะไรให้ถ้าไม่มี BOQ
4.1แยกใบวัสดุ / ใบค่าแรงสร้างใบเสนอราคาเป็นสองใบจากข้อมูลชุดเดียว ใบวัสดุและใบค่าแรง เพื่อให้ออก PO แยกสองฝั่งต้องแยกบรรทัดและทำสองใบเอง ยอดสองใบอาจไม่ตรงกับต้นทาง
4.2สรุปท้ายใบPreliminaries, Overhead & Profit, Performance Security และหัก ณ ที่จ่าย คำนวณจากยอดและอัตราที่ตั้งไว้ใน BOQไม่มีที่เก็บอัตราและฐานคำนวณ ต้องคิดและใส่ท้ายใบเอง
4.3Cut List ที่มาทีหลังนำเข้าและเทียบ Cut List หลังขาย รวมงานโคม / เจดีย์บัวที่ราคาตั้งไว้ก่อนแล้วมีรายการตัดตามมาระบบแจ้งว่าใบไม่ได้สร้างจาก BOQ นำเข้า Cut List ไม่ได้
4.4เทียบยอดที่เสนอกับยอดจริงเก็บยอดตอนเสนอราคาไว้ เมื่อเลือก Slab จริงแล้วยอดเปลี่ยน ระบบเทียบและเตือนเมื่อสรุปท้ายใบไม่ตรงไม่มียอดตั้งต้นให้เทียบ ยอดที่เปลี่ยนไปไม่มีใครเห็น
4.5ตารางงานโครงการระยะเวลาและ milestone ต่อโซน คัดลอกไปยังใบเสนอราคาตอนสร้าง เพื่อใช้วางแผนงานและเรียกเก็บเงินตามงวดต้องกรอกระยะเวลาและ milestone ทีละบรรทัดในใบเสนอราคาเอง
