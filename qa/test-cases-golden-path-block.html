  • ทำตามทีละขั้นด้วยคู่มือ คู่มือกดตาม Block (มีเหตุผลของแต่ละค่าที่กรอก) · เอกสารนี้ใช้ตรวจผล
  • ต้องทำ คู่มือกดตาม Setup ระบบ ตอน 2 มาก่อน เพื่อให้มีสินค้า Block และ Slab ตัวอย่าง
  • ขอบเขต 6 เคส: รับ Block เข้าคลัง 3 เคส · ใบแจ้งหนี้และแก้ขนาด 2 เคส · ตัดเป็น Slab 1 เคส
  • Golden Path เดิมของ Block (ซื้อ Block ถึงตัด, Block ถึง Slab ถึง FG) ไม่ได้แก้ ยังใช้ได้ตามเดิม
