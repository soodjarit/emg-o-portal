สวิตช์ BOQ = ใบเสนอราคาเริ่มต้นจากเอกสารประเมินราคา (Bill of Quantities) ก่อน แทนที่จะพิมพ์รายการลงใบเสนอราคาตรงๆ — เอกสารนี้เดินครบทุกขั้น: เลือก Rate → นำเข้า Cut List จริง → เพิ่มวัสดุสิ้นเปลือง + ค่าแรงติดตั้งหน้างานรายโซน → ออกใบเสนอราคา → Confirm → ราคาถูกล็อก ไม่เปลี่ยนแม้เลือก Slab จริง (ไม่ต้องเปิดสวิตช์ Project เลย)

เอกสารนี้ให้ผู้ใช้ทดสอบเอง: เดินตามขั้นตอนตามลำดับ แล้วติ๊ก "ผ่าน/ไม่ผ่าน" + จดหมายเหตุในคอลัมน์ขวาสุด ทดสอบบน eg-tst (หรือ mbx-ee-dev) ตัวเลขใน "Expected Result" ทุกจุดผ่านการรันจริงผ่านโค้ด (odoo shell แล้ว rollback) บน eg-tst วันที่ 1 ต.ค. 2026 ไม่ได้กะประมาณ · ไฟล์ Cut List ที่ใช้: cutlist-import-example-marine-hotel.xlsx (Library > ตัวอย่างเอกสารจากระบบ) · หลังมีการ deploy ให้กด hard refresh (Cmd+Shift+R) ก่อนทดสอบทุกครั้ง ไม่เช่นนั้นหน้าจออาจยังเป็นเวอร์ชันเก่า
ข้อจำกัดของการล็อกราคา (ยังไม่ครอบคลุม — ทราบแล้ว): (1) ล็อกเฉพาะ Slab แบบ serial (Mode 2/3 ที่ใช้ Select Slabs) — โหมด Lot และ "Sell Whole Block" ยังไม่ล็อก (2) ถ้าเลือก Slab มากกว่าที่เสนอ ลูกค้าจะได้แผ่นเพิ่มในราคารวมเดิม ส่วนต่างโผล่ในรายงานแต่ยังไม่มี popup เตือนตอนเลือก (3) บรรทัดวัสดุสิ้นเปลือง/ค่าแรงติดตั้งไม่ถูกล็อก (เป็นบรรทัดบริการธรรมดา แก้ได้อิสระ) (4) คอลัมน์ส่วนต่างในรายงานเป็นค่าคำนวณสด ยังจัดกลุ่ม/กรองตามส่วนต่างไม่ได้ (5) ผ่านการคลิกจริงใน browser ครบทุกขั้นแล้ว (Playwright บน eg-tst, 1 ต.ค. 2026) — ตัวเลขทุกตัวในเอกสารตรงกับหน้าจอจริง ยกเว้นฝั่งใบ Draft ของ TC-BOQ-21 ที่ตรวจจากใบ BOQ อื่น; หากหน้าจอของคุณต่างจากที่เขียนไว้ ให้ติ๊ก "ไม่ผ่าน" แล้วจดหมายเหตุ
