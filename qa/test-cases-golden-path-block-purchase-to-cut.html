แก้/เพิ่ม รอบ 14 ต.ค. 2569 (v109.24) — ใบคืนตีมูลค่าเท่าใบรับของเดิมของก้อนนั้น (55,000 ตามตัน 5.50 × 10,000) ไม่ใช่ราคา FIFO ชั้นเก่าสุด · ตัวอย่างนี้สร้างบิลผู้ขายไว้ก่อนคืนเพื่อใช้ต่อใน TC-GP-BPC-14
ใบคืน Block ขึ้น Ready พร้อมก้อนเดิมให้เองและเลือกได้เฉพาะก้อนของใบรับของเดิม · คืนได้เฉพาะ Block ที่ยังไม่ถูกตัด · คอลัมน์ Qty (Ton) บนใบคืนแสดง 5.40 (คำนวณจาก CBM) ต่างจากตันตามใบส่งของ 5.50 แต่มูลค่าและใบลดหนี้ใช้ 5.50
 มี PO และใบรับของที่ Done ของ Block 1 ก้อนที่ยังไม่ถูกตัด และมีบิลผู้ขายที่ Posted (ทดสอบด้วย PO แยกต่างหาก ไม่ใช่ P00295)
  1. เปิดใบรับของที่ Done กดปุ่ม Return
  2. กด Return All (ช่อง Quantity ตอนเปิดเป็น 0.00 เป็นปกติ) แล้วกด Return
  3. ใบคืนขึ้นสถานะ Ready — ตรวจว่าเป็น Block ก้อนเดิม แล้วกด Validate
  4. เปิดหน้า Block ของก้อนนั้นดูผล
