Golden Path Test Case

ขายวัสดุแบบ Lot-Mode (Slab ที่เราคุมสต็อกเป็น Lot)

อัปเดตล่าสุด: 27 กันยายน 2026
ตาม ADR-072 Decision 4 — ระบบสต็อกจริงของวัสดุแบบ Lot-Mode เปลี่ยนจาก "รับตร.ม. ตรงๆ" เป็น "นับจำนวนแผ่น" แล้วคำนวณตร.ม. ให้อัตโนมัติ พร้อมแก้บั๊กที่พบระหว่างทาง: ระบบเดิมอาจปล่อยให้ขายซ้ำสต็อกที่ถูกจองไปแล้วจากออเดอร์อื่น (oversell) เอกสารนี้เดินสดจริงผ่านเบราว์เซอร์ (Playwright) บน eg-tst ครบทุกขั้นตอน ตั้งแต่ขายจนถึงเห็นผลบนหน้าจอ native ของ Odoo เอง
Flow เดียวจบ: สร้าง Sale Order → เลือกวัสดุ Lot-Mode → กด "Select Lot Stock" เลือกล็อต + จำนวนแผ่น → ยืนยัน Order → ระบบจองสต็อกจริงทันที (Delivery พร้อมส่ง) → เช็คหน้า Material เห็นยอด "ตร.ม. พร้อมขาย" อัปเดตถูกต้อง → เช็คฟอร์ม Lot/Serial Number ของ Odoo เอง เห็นขนาดแผ่น + ตร.ม. คำนวณให้อัตโนมัติ
L1 เพิ่มวัสดุ Lot-Mode ลงใบเสนอราคา — ปุ่ม "Select Lot Stock" โผล่ให้กด
ทำ:
  1. สร้างใบเสนอราคาใหม่ ใส่ลูกค้า
  2. เพิ่มสินค้า: เลือกวัสดุที่เป็น Lot-Mode (เช่น หินราคาถูกที่ตั้งค่าไว้แบบ "ขายเป็นล็อต")
✓ ผลที่ควรเห็น: บรรทัดสินค้าโผล่ปุ่มลิงก์ "Select Lot Stock" ให้กดทันที — ต่างจากวัสดุปกติที่ไม่มีปุ่มนี้
L2 กด Select Lot Stock — กรอกเป็น "จำนวนแผ่น" ไม่ใช่ตร.ม.
ทำ: กดปุ่ม "Select Lot Stock" → เลือกล็อต (Block/Lot) → กรอก "Quantity to Sell (Pieces)" เป็นจำนวนแผ่น
✓ ผลที่ควรเห็น: หน้าจอโชว์ "Remaining Pieces (Lot)" และ "Remaining Sq.Mt. (Lot)" ของล็อตนั้น พร้อมช่อง "≈ Sq.M (estimate)" คำนวณตร.ม.โดยประมาณให้อัตโนมัติจากจำนวนแผ่นที่กรอก (จำนวนแผ่น × ขนาดมาตรฐานของวัสดุนั้น)
L3 ยืนยัน Order — ราคาแปลงถูกต้อง + สต็อกถูกจองจริงทันที
ทำ: กด "Confirm Selection" ในหน้าต่าง → กด "Confirm" ยืนยันใบสั่งขาย
✓ ผลที่ควรเห็น: จำนวนบนบรรทัดสินค้ากลายเป็นจำนวนแผ่น ราคารวมคำนวณถูกต้อง (ราคาต่อตร.ม.เดิม × ตร.ม.จริงที่ขาย) และมีปุ่ม "Delivery" โผล่ที่หัวเอกสาร — กดเข้าไปดูจะเห็นสถานะ "Ready" (จองสต็อกสำเร็จ) ทันทีไม่ต้องรอ
L4 หน้า Material — ยอด "ตร.ม. พร้อมขาย" อัปเดตถูกต้องทันที (ADR-072 Decision 4)
ทำ: เปิดหน้า Stone Slab → Configuration → Materials → เปิด Material ที่เพิ่งขายไป
✓ ผลที่ควรเห็น: มุมขวาบนของฟอร์มมีปุ่มสรุป "ตร.ม. พร้อมขาย" โชว์ยอดรวมที่ถูกต้อง — หักลบส่วนที่เพิ่งขายไปแล้วด้วย (ไม่ใช่แค่ยอดรวมทั้งหมดที่เคยรับเข้ามา) กดปุ่มนี้จะพาไปดูรายการ Block/Lot ทั้งหมดของวัสดุนี้ได้ทันที
L5 ฟอร์ม Lot/Serial Number ของ Odoo เอง — เห็นขนาดแผ่น + ตร.ม. โดยไม่ต้องเปิดหน้า Stone
ทำ: เมนู Inventory → Products → Lots / Serial Numbers → เปิดล็อตของ Material นี้ (ชื่อ "...-LOT")
✓ ผลที่ควรเห็น: ฟอร์มมาตรฐานของ Odoo เอง (ไม่ใช่หน้าจอ custom ของ Stone) มี section "Stone Slab Dimensions" โผล่มาเพิ่ม โชว์กว้าง×ยาว×หนา และสรุปเป็นตร.ม. ให้ — ประโยชน์: ฝ่ายคลัง (Factory) ที่เข้าผ่านเมนู Inventory โดยตรงก็เห็นข้อมูลนี้ได้เลย ไม่ต้องสลับไปเปิดหน้า Stone Material/Bundle
เดินสดจริงผ่าน Playwright บน eg-tst (Material ทดสอบ "E2E GP Test Onyx (Lot-Mode)", 20 แผ่น × 2 ตร.ม./แผ่น) — ทุกภาพหน้าจอในเอกสารนี้คือของจริงจากการรันจริง ไม่ใช่ mockup
