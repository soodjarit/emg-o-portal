E2E Full Walkthroughs
เดินสดครบวงจร แบ่งตามเฟส — Ensure Supply + Demand Generation (5 โหมดขาย) ครบแล้วทั้งหมด แยกขั้นตอนซื้อหินออกจากทุกโหมดเรียบร้อย
Demand Generation — ขาย 5 โหมด นับจากมีของในสต็อกแล้ว
M1
E2E — โหมด 1: ขายก้อนหินทั้งก้อน (Block Sale)
เดินสดจากมี Block พร้อมขายอยู่แล้ว → เลือกก้อนขายทั้งก้อน → ยืนยัน SO → เคสขายข้ามบริษัทอัตโนมัติ → ส่งของจริงแบบ dropship → ออกใบแจ้งหนี้ — พร้อมผังไฮไลท์ทีละขั้นตอน แยกจากขั้นตอนซื้อหินแล้ว
17 ส.ค. 2026ปรับโครงสร้างใหม่
→
M2
E2E — โหมด 2: ขายแผ่นหินสำเร็จรูป (Ready-Made Slab)
เดินสดจากมีแผ่น Slab พร้อมขายอยู่แล้ว → เลือกแผ่นตามเลข Serial (เลือกได้หลายแผ่นพร้อมกัน) → ยืนยัน SO → สแกน Serial ก่อนส่ง → ออกใบแจ้งหนี้ — เหลือแค่ 4 ขั้นตอน แยกจากขั้นตอนซื้อหินแล้ว (พ่วงเส้นทางหินถูก/แบบล็อตไว้ในเดคเดียวกัน)
17 ส.ค. 2026ปรับโครงสร้างใหม่
→
M3
E2E — โหมด 3: ตัดตามสั่ง (Cut-to-Order)
เดินสดจากมี Block พร้อมอยู่แล้ว → ยืนยัน SO ทั้งที่ยังไม่มีแผ่นจริง → ระบบขึ้นคิวอัตโนมัติที่ Factory Worklist → ฝ่ายผลิตเลือกก้อน+ระบุขนาดตัดเองผ่าน Manufacturing Order → ราคาคำนวณอัตโนมัติ → สแกน Serial ก่อนส่งของ → ออกใบแจ้งหนี้ — แยกจากขั้นตอนซื้อหินแล้ว
17 ส.ค. 2026ปรับโครงสร้างใหม่
→
M4
E2E — โหมด 4: งานโครงการ (Sold-as-Project)
เดินสดตั้งแต่ทำ BOQ ประเมินราคาจาก Rate Library → สร้างใบเสนอราคา → ติ๊ก Sold as Project ยืนยัน SO → ระบบสร้าง Project+Task+Milestone 30/40/30 อัตโนมัติ → ติดตามผ่าน Gantt → วางบิลตามงวดที่ระบบหักยอดจ่ายไปแล้วให้เอง — ไม่ผูกกับ Block/Slab ไม่ต้องพึ่ง Ensure Supply
13 ส.ค. 2026
→
M5
E2E — โหมด 5: ผลิตสินค้าสำเร็จรูป (FG Production)
เดินสดจากมี Block พร้อมอยู่แล้ว → ยืนยัน SO สินค้าสำเร็จรูป → Factory Worklist → ตัด Slab ดิบก่อนด้วย Cut to Order → Produce FG เลือก Slab + ระบุผลผลิตทุกชิ้น (รวม byproduct) → Complete FG Production ได้สต็อกจริงพร้อม Lot แยกกัน → ส่งของไม่ต้องสแกน Serial → ออกใบแจ้งหนี้ — แยกจากขั้นตอนซื้อหินแล้ว
17 ส.ค. 2026ปรับโครงสร้างใหม่
→
