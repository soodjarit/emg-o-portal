Management & Accounting
บริหารจัดการ, ต้นทุน, กำไร, บัญชี
1
กำไรรายโครงการ (Analytic Accounting)
ผูก Analytic Account เข้ากับ Bundle ครั้งเดียว — ต้นทุนและรายได้ทั้งสายแปะป้ายให้อัตโนมัติ จนเห็นกำไรจริงของแต่ละโครงการ
→
2
ใบรับรองหัก ณ ที่จ่าย (WHT Certificate)
พิมพ์แบบ 50 ทวิ ได้จากบิลผู้ขายโดยตรง — อัตราภาษีมีอยู่แล้วในระบบ ไม่ต้องตั้งค่าเพิ่ม
→
3
ต้นทุนหินก้อน + Landed Cost
รู้ต้นทุนจริงตั้งแต่วันนำเข้า ไม่ต้องรอตัดแผ่น — ค่าขนส่งกระจายตามสัดส่วนจริง และตรวจสอบย้อนกลับไปหาบิลจริงได้เสมอ
→

E2E Full Walkthroughs
เดินสดครบวงจรตั้งแต่เปิดใบขายจนถึงรับเงิน — อีก 2 Mode รออัปเดตเนื้อหาก่อนเพิ่มกลับเข้ามา
สำหรับพาลูกค้าดูสด — ไล่ทีละขั้นตอนพร้อมผังไฮไลท์ตำแหน่ง + หน้าจอจริงทุกจุด
M1
E2E — โหมด 1: ขายก้อนหินทั้งก้อน (Block Sale)
เดินสดตั้งแต่ซื้อก้อนหินเข้าคลัง → ขายทั้งก้อน → ยืนยัน SO → เคสขายข้ามบริษัทอัตโนมัติ → ส่งของจริงแบบ dropship → ออกใบแจ้งหนี้ — พร้อมผังไฮไลท์ทีละขั้นตอน
→
M2
E2E — โหมด 2: ขายแผ่นหินสำเร็จรูป (Ready-Made Slab)
เดินสดตั้งแต่ตัดแผ่นเก็บสต็อกล่วงหน้า → เลือกแผ่นตามเลข Serial (เลือกได้หลายแผ่นพร้อมกัน) → ยืนยัน SO → สแกน Serial ก่อนส่งของ → ออกใบแจ้งหนี้ — พร้อมผังไฮไลท์ทีละขั้นตอน
→
M3
E2E — โหมด 3: ตัดตามสั่ง (Cut-to-Order)
เดินสดตั้งแต่ยืนยัน SO ทั้งที่ยังไม่มีแผ่นจริง → ระบบขึ้นคิวอัตโนมัติที่ Factory Worklist → ฝ่ายผลิตเลือกก้อน+ระบุขนาดตัดเองผ่าน Manufacturing Order → ราคาคำนวณอัตโนมัติ → สแกน Serial ก่อนส่งของ → ออกใบแจ้งหนี้ — พร้อมผังไฮไลท์ทีละขั้นตอน
→
สำหรับทีมงาน — สคริปต์ซ้อมพรีเซนต์สด/เดโม ไม่จำเป็นต้องอ่านเพื่อใช้งานทั่วไป
1
E2E — PO to INV (ตัดแผ่นด้วยมือ)
เดินสดครบวงจร ตั้งแต่ Purchase Order → Bundle → ตัดแผ่นเอง → ขาย → Invoice → Vendor Bill — ผูก Analytic Account ตัวเดียวตามรอยต้นทุน+กำไรทั้งสาย พร้อมจุดห้ามลืมที่เจอจริง
→
2
E2E — Intercompany Trade (Select Slabs ข้ามบริษัท)
เงื่อนไขที่ต้องมีให้ขายข้ามบริษัทได้ + เดินสดครบวงจรตั้งแต่เลือกแผ่นข้ามบริษัท → Auto Intercompany → ส่งของตรงถึงลูกค้า → Invoice → รับชำระเงิน — รวมจุดที่เผลอ Post/Pay ผิดจริงและวิธีแก้
→
3
E2E — Select Lot Stock (ขายแบบล็อต) + รับชำระเงิน
เดินสดครบวงจร ตั้งแต่เปิดใบขาย → เลือกล็อตหินที่ตั้งราคาแบบตารางเมตร → ยืนยันขาย → ส่งของ → Invoice → รับชำระเงิน — พร้อมจุดห้ามลืมตอน Validate ที่เจอจริง
→
