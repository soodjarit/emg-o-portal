E2E Full Walkthroughs

Demand Generation — ขาย 5 โหมด นับจากมีของในสต็อกแล้ว
M1
E2E — โหมด 1: ขายก้อนหินทั้งก้อน (Block Sale)
เดินระบบจริงจากมีก้อนหินพร้อมขายอยู่แล้ว → เลือกก้อนขายทั้งก้อน → ยืนยันใบสั่งขาย → กรณีขายข้ามบริษัทที่ระบบจัดการให้อัตโนมัติ → ส่งของตรงถึงลูกค้าปลายทาง → ออกใบแจ้งหนี้ — พร้อมผังไฮไลท์ทีละขั้นตอน แยกจากขั้นตอนรับหินเข้าคลังแล้ว
21 ส.ค. 2026ปรับปรุงเนื้อหาแล้ว
→
M2
E2E — โหมด 2: ขายแผ่นหินสำเร็จรูป (Ready-Made Slab)
เดินระบบจริงจากมีแผ่นหินพร้อมขายอยู่แล้ว → เลือกแผ่นตามหมายเลขกำกับ (เลือกได้หลายแผ่นพร้อมกัน) → ยืนยันใบสั่งขาย → ตรวจสอบแผ่นก่อนส่งของ → ออกใบแจ้งหนี้ — เพียง 4 ขั้นตอน แยกจากขั้นตอนรับหินเข้าคลังแล้ว (รวมเส้นทางหินราคาประหยัดแบบนับจำนวนไว้ในเอกสารเดียวกัน)
21 ส.ค. 2026ปรับปรุงเนื้อหาแล้ว
→
M3
E2E — โหมด 3: ตัดตามสั่ง (Cut-to-Order)
เดินระบบจริงจากมีก้อนหินพร้อมอยู่แล้ว → ยืนยันใบสั่งขายทั้งที่ยังไม่มีแผ่นจริง → ระบบขึ้นคิวงานตัดให้ฝ่ายผลิตอัตโนมัติ → ฝ่ายผลิตเลือกก้อนและระบุขนาดที่จะตัด → ราคาคำนวณให้อัตโนมัติ → ตรวจสอบแผ่นก่อนส่งของ → ออกใบแจ้งหนี้ — แยกจากขั้นตอนรับหินเข้าคลังแล้ว
