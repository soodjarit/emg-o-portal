04 ขายเป็นแผ่น (ไม่แปรรูป)

Flow นี้ใช้เมื่อลูกค้าซื้อแผ่นหินไปติดตั้งเองเลย ไม่ต้องการให้ทางร้านเจาะ/ตัดอะไรเพิ่ม

ขั้นตอน

จากหน้า Sales Order ปกติ เพิ่ม Order Line เลือก Product ที่เป็นวัสดุหิน (stone material) — ระบบจะแสดงปุ่ม "Select Slabs" ต่อท้ายชื่อสินค้าในบรรทัดนั้นให้อัตโนมัติ

คลิก "Select Slabs" จะเปิด wizard ขึ้นมา:

กด "Add a line" → เลือก Block → ระบบจะแสดงเฉพาะแผ่นที่สถานะ Available และตรงกับ Product ของบรรทัดนั้นเท่านั้น (รวมทุก Warehouse ที่มีสิทธิ์เห็น รวมถึงข้ามบริษัท EG/ES — ดู บทที่ 08: ขายข้ามบริษัท (EG↔ES)):

เลือกแผ่นที่ต้องการ (เลือกได้หลายแผ่น) แล้วกด Select → แผ่นจะถูกเพิ่มเข้า wizard:

กด "Confirm Selection" — จำนวน (Quantity) บน Order Line จะอัปเดตตามจำนวนแผ่นที่เลือกอัตโนมัติ:

เคล็ดลับเปิด wizard ซ้ำได้ (Session 25)
ถ้ากลับมาเปิด "Select Slabs" ซ้ำบน line ที่มีแผ่น hold ไว้แล้ว (เช่น ลูกค้าสั่งผ่านเว็บ eCommerce มาก่อน — ดู บทที่ 09: eCommerce Catalog (`/stone-catalog`)) ระบบจะโชว์แผ่นที่ hold ไว้แล้วให้เห็นในลิสต์ด้วย (คอลัมน์ Status บอกว่า Available/Hold) สามารถเพิ่มแผ่นใหม่หรือเอาแผ่นเดิมออก (จะคืนสถานะเป็น Available อัตโนมัติ) ได้จากหน้าเดียวกันเลย

กด Confirm เพื่อยืนยัน SO — ระบบจะ:

1
เปลี่ยนสถานะแผ่นที่เลือกจาก Available → Hold ทันที พร้อมผูก Customer + เลข SO
2
สร้าง Delivery Order ให้อัตโนมัติ (smart button "Delivery" ที่มุมบน)

ขั้นตอนต่อไป (สแกนยืนยัน + ส่งของ + เซ็นรับ) ดูที่ บทที่ 06: ส่งของและยืนยันการรับ
