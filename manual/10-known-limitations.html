10 ข้อจำกัดและบั๊กที่ทราบ

อัปเดตล่าสุด: 25 ตุลาคม 2569 · ตรวจกับระบบ stone_slab_inventory 19.0.2.109.37 / boq_estimation 1.43 · รวบรวมจากหัวข้อข้อจำกัดของบทที่ 30–34 และผลทดสอบใบเสนอราคา 25 ต.ค. บนระบบทดสอบ · บั๊กที่แก้แล้วช่วง ก.ค.–ส.ค. ย้ายไปไว้ที่ ประวัติบั๊กที่แก้แล้ว

หน้านี้ระบุสิ่งที่ระบบยังทำไม่ได้ หรือยังไม่ได้ทดสอบ ณ วันที่ข้างบน แยกตามประเภทสินค้า รายการที่รอฝ่ายบัญชีลูกค้ายืนยันขึ้นป้าย "รอบัญชี"

การเสนอราคาและการขาย

เรื่องสถานะ / วิธีหลีกเลี่ยง
Block: จำนวนถูกแทนที่ตอน Confirmตอนกด Confirm ระบบเลือก Block ให้เองและเปลี่ยนจำนวนบรรทัดเป็นปริมาตรทั้งก้อน ยอดจึงเปลี่ยน (ทดสอบ: เสนอ 1 ลบ.ม. ได้ก้อน 5.04 ลบ.ม. ยอด 121,500 → 612,360) ถ้าต้องการระบุก้อน ให้เลือกด้วย Sell Whole Block ก่อน Confirm แล้วตรวจยอดอีกครั้ง รอตัดสินใจว่าจะล็อกจำนวนที่เสนอหรือไม่
Slab Serial: เสนอเป็น ตร.ม. โดยไม่รู้ขนาดแผ่นยังไม่รองรับ ราคาจะเป็น 0 ใช้ Slab แบบ Lot (ใส่ ตร.ม. ได้) หรือกรอกขนาด L × H (เมตร) ที่จะเสนอ
นำเข้า Cut List หลัง Confirm ใบเสนอราคา Slabยังไม่รองรับ (รองรับเฉพาะ FG ผ่าน BOQ ที่ขายเป็น ตร.ม. แล้วนำเข้า Cut List ทีหลัง ซึ่งผ่านการทดสอบบน eg-tst แล้ว แต่ mbx-ee-dev ยังไม่ได้อัปเป็น boq 1.43)
หินที่ยังไม่ตั้ง List Priceราคาถูกรีเซ็ตเป็น ฿0 ตอน Confirm ให้ตรวจ List Price ของ Material ก่อนเสนอราคา (เจอจริงกับสินค้าทดสอบ: ราคา 1 บาท)
นำเข้าใบเสนอราคาจาก Excelยังเป็นแผน ยังไม่ได้พัฒนา
สิทธิ์ผู้ใช้ระดับต่ำBlock ต้อง Sale - Supervisor ขึ้นไป, Slab ต้อง B2B ขึ้นไป, FG ทุกระดับ ตรวจจากโค้ด ยังไม่ได้ล็อกอินทดสอบรายกลุ่มบนหน้าจอ

Block (บทที่ 30)

  • การคืน Block ที่ถูกตัดบางส่วนไปแล้ว ยังไม่ได้ทดลองบนหน้าจอจริง
  • Block ที่ไม่มี "ตันตามใบส่งของ" และการคืนที่ย้อนหาตันของใบรับของไม่ได้ ยังออกบิลหรือใบลดหนี้เป็น ลบ.ม. แบบเดิม อาจคลาดเล็กน้อยจากการปัดเศษ
  • [รอบัญชี] ใช้บัญชีสินค้าคงคลังเดียวกันสำหรับ Block และ Slab หรือแยก และยืนยันการเขียนบิล Block เป็นตัน
  • ใบตัดเก่าบางใบ (ก่อน 4 ต.ค. 2569) หักสต็อกจากที่ผิด ทีมดูแลระบบจะทยอยตรวจแก้ บิลของใบสั่งซื้อที่เปิดก่อน 4 ต.ค. อาจตั้งเป็น "ตามที่สั่ง" ให้ตรวจก่อน Confirm

Slab (บทที่ 31)

  • การตัดทิ้งแผ่นชำรุด (Scrap): ปุ่มทำงานได้ แต่รายการบัญชีของการตัดทิ้งยังไม่ได้ตรวจ
  • การรับคืนยังไม่รวมการออกใบลดหนี้ให้ลูกค้า
  • การขายข้ามบริษัท (EG↔ES) และการซื้อ Slab สำเร็จรูปแล้วออกใบแจ้งหนี้ผู้ขาย ยังไม่ได้เดินจริงหลังรอบ Slab = Lot
  • เศษหินที่เหลือจากใบตัดยังไม่ถูกบันทึกกลับเข้าสต็อกเป็นแผ่นหรือเศษ
  • [รอบัญชี] ตอนตัด Block ออกและ Slab เข้าในบัญชีเดียวกัน ยอดสุทธิ 0 จะแยกบัญชีหรือไม่

FG (บทที่ 32)

  • ขั้นตอนบนแท็บ Work Orders (จับเวลาแต่ละขั้น) การคืน FG จากลูกค้า การตัดทิ้งเศษชำรุด และการขายข้ามบริษัท ยังไม่ได้ทดลอง
  • ค่าแรงและค่าแปรรูปเป็นอัตราตั้งต้นสำหรับทดสอบ ต้องตั้งเป็นค่าจริงก่อนใช้งานจริง งานแปรรูปแบบบริการยังไม่มีต้นทุนของตัวเอง
  • ต้นทุนในสูตร BOQ ของ Custom FG เป็นค่าประมาณ (ใช้ราคา Rate ไม่ใช่ต้นทุน Slab จริง) ค่าแรงและวัสดุสิ้นเปลืองที่ไม่มีสินค้าในสูตรไม่ถูกลงบัญชี
  • ถ้าไม่บันทึกเศษที่เหลือ ต้นทุน Slab ทั้งแผ่นเข้า WIP/FG ทั้งหมด
  • ปุ่ม "คัดลอกแผนเป็นขนาดจริง" มีเฉพาะใบตัดหิน (Cutting Plan) ยังไม่มีในตารางแผ่นของใบสั่งตัด (Cut Order)
  • ข้อความบางจุดบนหน้าใบสั่งผลิตยังค้าง (แถบเหลือง "ขั้นตอนถัดไป" และหัวข้อซ้ำ) ไม่กระทบการทำงาน

Landed Cost และต้นทุนการผลิต (บทที่ 33–34)

  • เพิ่ม Block เข้าตู้หลังลงต้นทุนไปแล้ว ระบบไม่ลงย้อนหลังให้ Block ใหม่ ใบรับของที่มี Block หลายตู้ปนกันต้องทำ Landed Cost เอง
  • บิลที่มาหลัง Block ถูกตัดหรือขายแล้ว ส่วนนั้นเข้า COGS ไม่ย้อนแก้ต้นทุน Slab ที่ตัดไปแล้ว [รอบัญชี]
  • Landed Cost แบ่งตามคิวอย่างเดียว ไม่มีตัวเลือกแบ่งตามน้ำหนักหรือมูลค่า
  • วิธีบันทึกค่าแรงของใบผลิตแต่ละชนิดยังไม่เหมือนกัน กฎ "ต้นทุน FG ไม่ต่ำกว่า 50% ของราคาขาย" และการลงค่าแรงเป็นต้นทุนขายทั้งก้อนตอนผลิตเสร็จ [รอบัญชี] (คำถามอยู่ที่หน้าคำถามถึงนักบัญชี)
  • ยังไม่มีตัวอย่างใบตัดที่บันทึกเวลาตามการทำงานจริงผ่านจอ Shop Floor ฟีเจอร์เลือกสถานี (ลบ/เพิ่ม) ทดลองบน eg-tst แล้ว แต่ยังรอ commit และเปิดใช้งานกับระบบจริง

ฟีเจอร์เสริมและงานติดตั้งระบบ

  • eCommerce Catalog: มีบางแผ่นที่กรอกราคาขายจริงแล้ว แผ่นอื่นแสดง ฿0 (ดู บทที่ 09)
  • Scan Station: ยังไม่มีเครื่องสแกนจริงมาทดสอบ (ทดสอบด้วยการจำลองผ่าน HTTP เท่านั้น) ดู บทที่ 11
  • Slabware Inbound API (ให้ระบบภายนอกส่งข้อมูล material/block/slab เข้ามา) ยังรอ payload spec จากผู้พัฒนาของลูกค้า และต้องสร้างใหม่บนโครง Slab = Lot
  • เมนู "Analytic Items" ไม่ขึ้นสำหรับผู้ใช้ทั่วไป เพราะอยู่ใต้กลุ่มสิทธิ์ "Show Accounting Features"
  • ไฟล์ static ของหน้า /stone-scan ผ่าน Cloudflare cache ได้สูงสุด 7 วัน หลัง deploy ผู้ใช้อาจต้อง hard refresh
