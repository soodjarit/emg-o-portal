23 การคืนสินค้า (Returns / RMA)

โจทย์

ก่อนหน้านี้ระบบไม่มีการจัดการการคืนสินค้าเลย — สถานะแผ่นหิน (stone.slab.status) มีแค่ available/hold/consigned/cut_loss/sold/remnant ไม่มีทางย้อนกลับจาก "Sold" เลย ถ้าลูกค้าคืนแผ่นหิน (ผิดขนาด/ชำรุดจากขนส่ง/ยกเลิกงาน) แล้วพนักงานใช้ปุ่ม Return มาตรฐานของ Odoo สต็อกจริงจะถูกต้อง แต่แผ่นนั้นจะค้างสถานะ "Sold" ตลอดไปในสายตาโมดูล — มองไม่เห็นใน Select Slabs wizard, ตัวนับ Block, หรือ Stock Take ทั้งที่ของจริงกลับเข้าคลังแล้ว

วิธีทำงานตอนนี้

1
ลูกค้าคืนแผ่นหิน — พนักงานใช้ปุ่ม Return มาตรฐานของ Odoo จากใบส่งของเดิม (Delivery Order → Return)
2
Validate ใบรับคืน — ระบบตรวจจับอัตโนมัติว่าเป็นการคืนสินค้าจริง (ไม่ใช่ใบรับสินค้าทั่วไป) แล้วเปลี่ยนสถานะแผ่นเป็น "Returned - Pending Inspection" ทันที
3
ไปที่เมนู Stone Slab → Slabs Pending Inspection เพื่อดูรายการแผ่นที่รอตรวจสอบทั้งหมด (ข้าม Block ได้ ไม่ต้องเปิดทีละ Block)
4
ตรวจสอบสภาพแผ่นจริง แล้วกดปุ่มตัดสินใจ — ในหน้า list กดได้ตรงแถวเลย หรือเปิดฟอร์มแผ่นแล้วกดปุ่มบนหัว
  • "ตรวจแล้ว: ขายต่อได้ (Available)" — แผ่นสภาพดี ขายต่อได้ทันที ล้างข้อมูลลูกค้า/SO เดิมออก กลับไปเป็น Available ปกติ
  • "ตรวจแล้ว: ชำรุด (Cut Loss)" — แผ่นเสียหาย ไม่สามารถขายต่อได้ เข้ากลุ่มเดียวกับของเสียจากการตัด
5
Block แต่ละใบมีปุ่ม "Returned" (smart button) โชว์จำนวนแผ่นที่รอตรวจสอบของ Block นั้นด้วย ถ้ามี

ข้อควรรู้ (เจอจากการทดสอบจริง)

บั๊กที่พบNative Return ของ Odoo ไม่ได้คืนของเข้า "Stone Hold"
ตอนออกแบบครั้งแรกคิดว่า Return จะคืนของกลับเข้าตำแหน่งเดิม (Stone Hold) แต่ทดสอบจริงแล้วพบว่า Odoo คืนเข้า warehouse Stock ทั่วไปแทน (picking type สำหรับรับของใช้ร่วมกับใบรับสินค้าทั่วไป ชี้ไปที่ Stone Hold ตรงๆ ไม่ได้ ไม่งั้นจะกระทบการซื้อของทั่วไป ดู บทที่ 15: การจัดซื้อ) ระบบเลยบันทึกตำแหน่งจริงที่ของไปตกไว้ (ไม่ใช่เดาตายตัว) แล้วดึงสต็อกจากตำแหน่งจริงตอนพนักงานกดปุ่มตัดสินใจ — พิสูจน์แล้วด้วยการอ่าน stock move ledger จริง ไม่ใช่แค่เดา

สรุป

Gap ที่เจอจากการอ่านโค้ดจริง (ไม่มีทางย้อนสถานะจาก Sold เลย) แก้แล้วครบ: ตรวจจับอัตโนมัติ + ขั้นตอนตรวจสอบก่อนตัดสินใจ (ตามที่ user เลือก ไม่ใช่ auto-resolve ทันที เพราะแผ่นหินอาจชำรุดจากการขนส่งจริง) + เมนูรวมให้พนักงานตามงานได้ง่าย ทดสอบจริงผ่าน browser ครบวงจร (ขาย → ส่งของ → คืนสินค้า → ตรวจสอบ → ตัดสินใจ)
