07 ต้นทุนสินค้า

เปิดฟอร์ม Block จะเห็น section Pricing & Cost:

คำเตือนcost/cost_sqmt/cost_cbm คือต้นทุนวัสดุเท่านั้น — ดู total_cost สำหรับต้นทุนรวม

cost (หน้า Slab) / cost_sqmt / cost_cbm (หน้า Block) ทุกช่องคำนวณจาก ราคาซื้อ (PO) + Landed Cost เท่านั้น — ไม่รวมค่าแรงตัด/แปรรูป หรือต้นทุนอื่นๆ (เช่น ค่าเสื่อมเครื่องจักร, overhead โรงงาน) ระบบมี tooltip เตือนไว้ในหน้าจอด้วยแล้ว — field นี้คงความหมายเดิมไว้ตลอด ไม่ถูกแก้แม้จะมีการเพิ่มค่าแรงตัดเข้าระบบแล้ว (ดูด้านล่าง)

อัปเดตเพิ่มค่าแรงตัดเข้าระบบแล้ว — field ใหม่ labor_cost / total_cost (2026-08-20)

Slab ทุกแผ่นมี 2 field ใหม่: labor_cost (ค่าแรงตัดโดยประมาณ) และ total_cost (= cost + labor_cost)

ตัดผ่านที่มาค่าแรง
Cut-to-Order (MRP) — มี mo_idต้นทุนจริงจาก workcenter cost/ชม. × เวลาที่ใช้จริงจาก Work Order — ตัวเลขเดียวกับที่ tag เข้า Analytic Account ตอน Complete Cut (ดู บทที่ 14: ผลิตตามสั่ง (MRP))
Add Slab Line (manual) — ไม่มี mo_idflat rate ต่อ Sq.Mt. ตั้งไว้ล่วงหน้าที่หน้า Material → Cutting Labor Cost / Sq.Mt. × slab_sqmt (ดู บทที่ 03: ตัดแผ่นและจัดการสต็อก)

ไม่มีการนับซ้ำ — ระบบเช็คจาก mo_id ก่อนเลือกสูตร ไม่เคยใช้ทั้งสองแหล่งพร้อมกัน หมายเหตุ: material ที่ตั้ง Costing Basis = "Count" จะไม่มีค่าแรงจาก flat rate (ไม่มีฐาน Sq.Mt. ให้คูณ)

สูตรคำนวณ:

  • PO Cost / Sq.Mt. = ราคาจาก Purchase Order Line (purchase_line_id.price_unit / total_sqmt หรือ price_subtotal สำหรับ PO แบบ CBM) — PO เป็นแบบ lump sum ต่อ Block
  • Landed Cost / Sq.Mt. = container.landed_cost_total กระจายตามสัดส่วน sqmt ของแต่ละ Block ใน container นั้น (คำนวณเอง ไม่ผ่านโมดูล stock_landed_costs มาตรฐาน เพราะ native split method เป็นระดับ product ไม่ใช่ระดับ slab)
  • Cost / Sq.Mt. = PO Cost + Landed Cost
  • slab.cost = bundle.cost_sqmt × slab.slab_sqmt (คำนวณแยกทุกแผ่น)
  • slab.labor_cost = ถ้ามี mo_id → Σ (workcenter.costs_hour × workorder.duration/60) ; ถ้าไม่มี → material.labor_cost_sqmt × slab.slab_sqmt
  • slab.total_cost = slab.cost + slab.labor_cost
  • slab.sale_price = bundle.sales_price_sqmt × slab.purchased_sqmt (ใช้แสดงราคาในหน้าเว็บ eCommerce ด้วย — ดู บทที่ 09: eCommerce Catalog (`/stone-catalog`))

Section SQ.MT. STATS ด้านล่างสรุปพื้นที่รวมแยกตามสถานะ (Total / Available / Hold / Sold) ให้เห็นภาพรวมมูลค่าสต็อกทันที
