ตัวอย่างใบเสนอราคาจริง 5 แบบ

ตัวอย่างใบเสนอราคาจากงานหน้างานประเภทต่างๆ — ใช้เทียบเคียงตอนออกใบเสนอราคาจริงว่าจะเลือกวิธีคิดแบบไหน

ตัวอย่างใบเสนอราคา — ไฟล์ 2: ค่าหิน แบบธรรมดา ตัวอย่างใบเสนอราคา — ไฟล์ 3: ค่าหิน+ค่าแรง ซื้อสแลป มีค่าจ้างตัด ตัวอย่างใบเสนอราคา — ไฟล์ 4: ค่าแรง ที่มีรายละเอียดแต่ทำแบบเหมารวม (CIRA Residences) ตัวอย่างใบเสนอราคา — ไฟล์ 5: ค่าแรงอย่างเดียว ตัวอย่างใบเสนอราคา — ไฟล์ 8: ใบเสนอราคาที่มีค่าขัดด้วย คิดเป็นเมตร

16ตัวอย่างใบเสนอราคา — ไฟล์ 2: ค่าหิน แบบธรรมดา

โจทย์ (จากไฟล์ต้นฉบับ)

ลูกค้าส่งใบเสนอราคาโครงการ "The Residences 38" — ขอราคาหิน Ocean black (ผิว Leather) ตัดตามขนาดหน้างานหลายจุด (ผนังหน้าลิฟต์, ธรณีประตู, พื้นบันได ฯลฯ) รวม 8 รายการ ราคา 3,900 บาท/SQM บวกค่าบริการเพิ่มเติมคิดตามพื้นที่รวมทั้งงาน (ไม่ใช่ต่อรายการ):

รายการหน่วยราคา
Dry Lay (วางเรียงก่อนติดตั้งจริง)ต่อ SQM รวม250
Coating (เคลือบผิว)ต่อ SQM รวม300
Delivery + Packingต่อ SQM รวม200

ชำระเงิน 30% มัดจำ / 70% ส่งของ

วิธีทำใบเสนอราคาใน Odoo

1
Sales → New → กรอก Customer
2
Add a product → เลือกวัสดุหิน (Ocean black Granite Slab) — ปุ่ม Select Slabs จะโผล่มาอัตโนมัติทันทีที่เลือกวัสดุหิน
คำเตือนต้อง Save ก่อนกด Select Slabs เสมอ
ถ้ากด Select Slabs บนใบที่ยังไม่เคย Save (สถานะยังเป็น "New") ระบบจะฟ้อง "Please save your changes first" — กด Save (ไอคอนรูปเมฆมุมซ้ายบน) ก่อนเสมอในใบเสนอราคาใหม่
3
Save แล้วกด Select Slabs — wizard จะเปิดรายการแผ่นที่ Available ของวัสดุนี้ทั้งหมด
4
เลือกแผ่นที่ต้องการ (ติ๊กช่องซ้ายมือ) → กด Select → Confirm — Quantity บน Order Line จะอัปเดตตามจำนวนแผ่นที่เลือกอัตโนมัติ
5
ตั้งราคาเอง — ระบบไม่คำนวณราคาให้อัตโนมัติจาก SQM × ราคา/SQM ต้องกรอกเองที่ช่อง Unit Price (คำนวณ: SQM ของแผ่นที่เลือก × 3,900 บาท)
เคล็ดลับวิธีคำนวณราคาเร็ว
เปิด Bundle ของวัสดุนั้นดู SQM ต่อแผ่น (หรือดูจาก Select Slabs wizard คอลัมน์ "Purchased ...") แล้วคูณด้วยราคา/SQM ที่ตกลงกับลูกค้าเอง — ไม่มี auto-calculate ในขั้นนี้ (ดู gap #2 ใน วิเคราะห์ใบเสนอราคา-BOQ-Import-Odoo)
6
Add a product อีกครั้งเพื่อเพิ่มค่าบริการ (Dry Lay/Coating/Delivery) — กรอก Quantity เป็น SQM รวมทั้งงาน (ไม่ใช่ต่อรายการ) และราคาต่อ SQM
7
ทำซ้ำสำหรับ Coating และ Delivery + Packing แล้ว Save — ยอดรวมจะคำนวณอัตโนมัติ

17ตัวอย่างใบเสนอราคา — ไฟล์ 3: ค่าหิน+ค่าแรง ซื้อสแลป มีค่าจ้างตัด

โจทย์ (จากไฟล์ต้นฉบับ)

โครงการ "Sale Gallery" — ขาย Slab Light Classico (Honed) ผนัง ST-108 พร้อมบริการเสริมผูกกับหินเส้นนั้นโดยเฉพาะ: ค่าตัด, Coating (นับเป็นขวด ไม่ใช่ SQM), ค่าแรงติดตั้ง — และมีเงื่อนไขการเงินที่ซับซ้อนกว่าปกติ:

  • ชำระค่าหิน 40% ทันที / 60% เครดิต 30 วัน หลังส่งของ
  • ชำระค่าแรง 40% ทันที / 60% เครดิต 30 วัน หลังส่งของ
  • หัก Retention 5% คืนใน 365 วัน (มาตรฐานงานก่อสร้าง)
  • ให้ลูกค้าออก PO มาที่ Empire Granite โดยตรง

วิธีทำใบเสนอราคาใน Odoo

1
Sales → New → กรอก Customer → ตั้ง Payment Terms เป็นแบบมีเงื่อนไขหลายงวด (สร้างครั้งเดียวใช้ซ้ำได้): Configuration → Payment Terms → New → ใส่ 3 บรรทัด (40% ทันที, 55% ที่ 30 วัน, 5% ที่ 365 วัน = Retention)
2
Add a product → เลือก Light Classico Marble Slab → Save → Select Slabs
3
Wizard เปิดรายการแผ่น Available ของ Light Classico
4
เลือกแผ่น → Select → Confirm → ตั้งราคาเอง (SQM ของแผ่น × ราคา/SQM ที่ตกลงกับลูกค้า)
5
Add a product เพิ่มค่าตัด (Slab Fabrication Service — ใช้ product ที่มีอยู่แล้วในระบบ ไม่ต้องสร้างใหม่)
ข้อมูลCoating คิดเป็นขวดในไฟล์นี้
ต่างจากไฟล์ 2 ที่ Coating คิดต่อ SQM รวม — ไฟล์นี้ระบุเป็น 4 ขวด ราคาต่อขวด ควรสร้าง product แยกชื่อชัดเจนว่า "Coating (ต่อขวด)" กับ "Coating (ต่อ SQM)" คนละตัว กันสับสนตอนออกใบเสนอราคาจริง (ดู gap #4 ใน วิเคราะห์ใบเสนอราคา-BOQ-Import-Odoo)
6
Save — ยอดรวมคำนวณอัตโนมัติ, Payment Terms แสดง "Retention 5%" ที่เลือกไว้ตอนต้น

18ตัวอย่างใบเสนอราคา — ไฟล์ 4: ค่าแรง ที่มีรายละเอียดแต่ทำแบบเหมารวม (CIRA Residences)

โจทย์ (จากไฟล์ต้นฉบับ)

19ตัวอย่างใบเสนอราคา — ไฟล์ 5: ค่าแรงอย่างเดียว

โจทย์ (จากไฟล์ต้นฉบับ)

งาน "ค่าแรง ซุ้ม ก ไก่ และ บัวบน (หลังที่ 18-24)" — ค่าแรงติดตั้งหินอย่างเดียว (Moleanos Beige ขัดเรียบ) ไม่มีขายหิน เหมือนไฟล์ 4 แต่เรียบง่ายกว่ามาก: ราคาต้นฉบับเป็น เหมารวมทั้งงานบรรทัดเดียว (980,710.64 บาท) ไม่มีราคาย่อยให้แยกเลยแม้แต่ระดับห้อง — รายละเอียดพื้นที่ (ผนัง 287 SQM, ผนังใต้ซุ้มโค้ง 7 SQM, Straight Profile 7 ม., ผนังบัวบน 68.6 SQM) เป็นแค่ข้อมูลอธิบายประกอบ

20ตัวอย่างใบเสนอราคา — ไฟล์ 8: ใบเสนอราคาที่มีค่าขัดด้วย คิดเป็นเมตร

โจทย์ (จากไฟล์ต้นฉบับ)

ใบเสนอราคาย่อย — ขาย Slab Ceppo (ขัดเรียบ) 1 แผ่น (3.23 SQM) ราคา 3,800/SQM พร้อมบริการเสริม 4 รายการ ที่น่าสนใจคือหน่วยราคาไม่เหมือนกันในใบเดียว:

รายการหน่วยราคา
Drawing (ทำแบบ)ต่อ SQM500
ลบมุม 2mm 1 ด้านต่อเมตร (ความยาวขอบ)200
ค่าน้ำยากันซึมเหมา (LS)200
ค่าขนส่งเหมา (LS)500

วิธีทำใบเสนอราคาใน Odoo

1
Sales → New → กรอก Customer
2
Add a product → เลือก Ceppo Marble Slab → Save → Select Slabs
3
Wizard เปิดรายการแผ่น Available ของ Ceppo
4
เลือกแผ่น → Select → Confirm → ตั้งราคาเอง (3.23 SQM × 3,800 = 12,274)
5
Add a product เพิ่มบริการเสริม — จุดสำคัญคือรายการ "ลบมุม 2mm" ต้องตั้ง UoM เป็น "m" (เมตร) ไม่ใช่ Units เหมือนรายการอื่น
ข้อมูลไม่ต้องสร้าง UoM ใหม่
Odoo มี UoM "m" (เมตร) อยู่แล้วในระบบเป็นค่าเริ่มต้น (Settings → Technical → Units of Measure) แค่ตั้ง product ตัวนี้ให้ default UoM เป็น "m" ตอนสร้าง product ก็ใช้ได้ทันที ไม่ใช่ gap ที่ต้องพัฒนาเพิ่ม
6
เพิ่ม Drawing (ต่อ SQM), ค่าน้ำยากันซึม, ค่าขนส่ง (เหมา) แล้ว Save
