01 ภาพรวมระบบ

ข้อมูลใน EMG-O จัดเรียงเป็นลำดับชั้น: Material → Block → Block → Slab

  • Material = ชนิดหิน เช่น Emperador Grey Light (1 Material = 1 Product ใน Odoo ไม่ใช้ Variants)
  • Block = ก้อนหินดิบจากเหมือง ซื้อเป็นหน่วย m³ (CBM) — มี Product แยกต่างหากจาก Slab (Phase 12)
  • Block = ชุดหินที่มาด้วยกัน 1 lot ผูกกับทั้ง Block (CBM) และ Slab (แผ่น) ของ material เดียวกัน
  • Slab = แผ่นเดี่ยวแต่ละแผ่นที่ตัดออกจาก Block ในบันเดิลนั้น แต่ละแผ่น track แยกกันด้วย:
  • Serial Number (Lot) เฉพาะแผ่น — 1 แผ่น = 1 lot (ตั้งแต่ ADR-009) เพื่อสแกนยืนยันตอนส่งของได้
  • Slab No. — เลขลำดับแผ่นในบันเดิล ไม่ซ้ำกันเสมอ (auto-assign)
  • สถานะ: Available / Hold / Consigned / Sold / Cut-Loss / Remnant

ตัวอย่างหน้าจอ Block Kanban (มุมมองภาพรวมของทุก Block พร้อม stats):

การ์ดแต่ละใบแสดง Warehouse, Material, สถานะแผ่น (Available/Hold/Consigned/Sold) และ sqmt รวม

Workflow การเปลี่ยนสถานะแผ่น

  • Available → Hold: อัตโนมัติเมื่อ SO confirm (ลูกค้าจอง ผ่าน Select Slabs wizard)
  • Hold → Available: อัตโนมัติเมื่อ unreserve / ยกเลิก SO / ยกเลิก line
  • Hold → Sold: อัตโนมัติเมื่อ Delivery Order validate (ผ่านการสแกนยืนยัน Serial ก่อนเสมอ — ดู บทที่ 06: ส่งของและยืนยันการรับ)
  • Available → Consigned: Internal Transfer ไปยัง location Consigned
  • Consigned → Sold: Transfer จาก Consigned ตอนขายได้จริง
  • Hold → Available (fabrication cancel): ถ้ายกเลิก Repair Order ที่ผูกกับแผ่น ระบบจะปล่อยแผ่นคืนอัตโนมัติ

2 Flow การขายหลัก

ระบบรองรับการขาย 2 แบบ ต่างกันตรงมีขั้นตอนแปรรูป (fabrication) แทรกหรือไม่:

1
ขายเป็นแผ่นเฉยๆ — ดู บทที่ 04: ขายเป็นแผ่น (ไม่แปรรูป)
2
ขายพร้อมเจาะช่องอ่างล้างหน้า — ดู บทที่ 05: ขายพร้อมแปรรูป (เจาะช่องอ่างล้างหน้า)

ทั้งสองแบบใช้ขั้นตอนรับสินค้า/ตัดแผ่น/เก็บสต็อกเดียวกันทั้งหมด (หัวข้อ 2-3) และจบด้วยขั้นตอนส่งของ/สแกน/เซ็นรับของเดียวกัน (หัวข้อ 6)
