3 อย่างนี้มีคนอื่นทำให้แล้ว ไม่ต้องกังวล

✕
ตั้งราคาต้นทุน/สร้าง Rate ใหม่
ทีม estimate เป็นคนคำนวณและตั้งราคาไว้ล่วงหน้าใน Rate Library — ถ้าหา Rate ที่ต้องการไม่เจอ แจ้งทีม estimate ให้เพิ่มให้ อย่าพิมพ์ราคาเองมือ
✕
ผูก Rate กับสินค้าจริง
ทีมปฏิบัติงานเป็นคนผูก Rate แต่ละตัวกับสินค้าจริงในคลังไว้ล่วงหน้า — คุณแค่เลือก Rate มาใช้ ไม่ต้องผูกเอง
✕
เลือกแผ่นจริง / คำนวณราคาใหม่
Select Slabs และ Recompute Price เป็นขั้นตอนที่ฝ่ายปฏิบัติงานทำ "หลัง" ลูกค้าตกลงซื้อแล้วเท่านั้น ไม่ใช่ตอนเสนอราคา
สรุป: งานของคุณคือแค่ประกอบ BOQ Document ให้ถูกต้อง แล้วส่งใบเสนอราคาให้ลูกค้าทันเวลา — แค่นั้นจบ

BOQ Documents → New→ กรอก Customer + Company→ % ปล่อย default ได้ถ้าไม่แน่ใจ

สถานการณ์จริง

ไม่แน่ใจ % Preliminaries/Overhead? ปล่อยเป็นค่า default ไปก่อนได้ ถามหัวหน้าทีมทีหลังได้ ไม่บล็อกการทำงาน
ขั้นตอนที่ 1 · เปิด BOQ Document + กรอกลูกค้า

รายละเอียดขั้นตอน

  • 1เปิด BOQ Estimation → BOQ Documents → กด New
  • 2กรอกชื่อ Customer + เลือก Company (ปกติเลือกถูกอยู่แล้วเป็นค่า default)
  • 3ค่า % Preliminaries/Overhead ปล่อยตามค่าเดิมได้ถ้าไม่มีเงื่อนไขพิเศษจากลูกค้า
  • 4Save เอกสาร แล้วไปขั้นตอนถัดไปได้เลย
จำง่ายๆ: หน้านี้เป็นแค่ "ใบปะหน้า" ของเอกสาร รายการหินจริงไปกรอกในขั้นตอนถัดไป
กรอก Customer — เปิดเอกสารใบแรก
ขั้นตอนที่ 2 · ใส่รายการ (เลือก Rate ที่มีอยู่แล้ว)

ไม่ต้องคำนวณราคาเอง แค่ค้นหาแล้วเลือก

Add a line→ พิมพ์ชื่อ Zone→ ค้นหา Rate จาก dropdown→ ใส่ Quantity
2
สถานการณ์จริง
ลูกค้าส่งแบบมาแยกเป็นโซน (เช่น "ชั้น 2 Lobby") อยากได้ราคาหินแยกตามโซน — แต่คุณไม่รู้ราคาต้นทุนของหินแต่ละแบบเลย
ข้อมูลที่กรอก → Key ที่ไหนใน Odoo
ข้อมูลตัวอย่างค่าจริงตำแหน่งใน Odoo
Zone (Schedule)พิมพ์ชื่อโซนเอง เช่น "ชั้น 2 Lobby"แท็บ BOQ Lines → คอลัมน์ Schedule/Zone
Rateพิมพ์ค้นหาชื่อหิน เช่น "ST1" แล้วเลือกจาก listแท็บ BOQ Lines → คอลัมน์ Rate (ค้นหาอย่างเดียว ไม่สร้างใหม่)
Quantityตามพื้นที่หน้างานจริงแท็บ BOQ Lines → คอลัมน์ Quantity
ราคา/หน่วย + ยอดรวมเติมให้อัตโนมัติไม่ต้องกรอกเอง — ระบบดึงจาก Rate ที่เลือก
ขั้นตอนที่ 2 · ใส่รายการ (เลือก Rate ที่มีอยู่แล้ว)

รายละเอียดขั้นตอน

  • 1แท็บ BOQ Lines → Add a line
  • 2พิมพ์ชื่อ Zone ตามหน้างานจริง (พิมพ์ซ้ำได้หลายบรรทัดถ้าโซนเดียวกันมีหลายรายการ)
  • 3คลิกช่อง Rate → พิมพ์ค้นหาชื่อหิน → เลือกจากลิสต์ที่มีอยู่แล้ว
  • 4ใส่ Quantity ตามหน้างานจริง — ราคา/หน่วยและยอดรวมขึ้นให้อัตโนมัติ ทำซ้ำจนครบทุก Zone แล้ว Save
หา Rate ไม่เจอในลิสต์? แจ้งทีม estimate ให้เพิ่มให้ — อย่าพิมพ์ราคาเองมือ เพราะจะไม่มี single source of truth เหมือนเดิม
เพิ่ม BOQ Lines — เลือก Zone + Rate ที่มีอยู่แล้ว + Quantity
ขั้นตอนที่ 3 · กดสร้างใบเสนอราคา

ปุ่มเดียว จบ — ได้ใบเสนอราคาพร้อมส่งลูกค้าทันที

กด "สร้างใบเสนอราคา"→ Sale Order ใหม่ทันที→ ตรวจยอดสรุป→ พร้อมพิมพ์/ส่งออก

สถานการณ์จริง
กรอก BOQ Document ครบทุก Zone แล้ว — ไม่ต้องมานั่งพิมพ์ใบเสนอราคาเองใน Word/Excel อีกชุด ระบบสร้างให้จากข้อมูลที่กรอกไว้แล้ว
ข้อมูลบน BOQ Document → ไป Key ที่ไหนบนใบเสนอราคา
ข้อมูลต้นทางปรากฏยังไงตำแหน่งบนใบเสนอราคา
Zone (Schedule)รวมยอดต่อ Zone ให้เองOrder Lines → Section header
Rate × Quantityรวมเป็น 1 บรรทัดสรุปต่อ ZoneOrder Lines → บรรทัด "BOQ Summary Line"
ก่อนส่งลูกค้า: ตรวจยอดสรุปให้ตรงกับที่คุยกับลูกค้าไว้ก่อนเสมอ — ถ้าตัวเลขดูแปลก แจ้งหัวหน้าทีมก่อน อย่าแก้ตัวเลขเอง
ลูกค้าขอใบแยก Material/Labor? ติ๊ก checkbox "Split Material/Labor Quotation" บน BOQ Document ก่อนกดสร้างใบเสนอราคา — ระบบจะออกให้ 2 ใบแยกกันทันที (พร้อมหัก WHT อัตโนมัติในใบ Labor) ตรงกับรูปแบบเอกสารที่ลูกค้าบางรายใช้จริง ดูตัวอย่างที่ เอกสาร BOQ Estimation อัปเดต →
ขั้นตอนที่ 3 · กดสร้างใบเสนอราคา

รายละเอียดขั้นตอน

  • 1กลับไปที่ BOQ Document ที่กรอกไว้
  • 2กดปุ่ม "สร้างใบเสนอราคา" ที่หัวฟอร์ม
  • 3ระบบสร้าง Sale Order ใหม่ทันที แบ่ง section ตาม Zone ให้เอง
  • 4ตรวจสอบยอดสรุปด้านล่างให้ตรงกับที่คุยกับลูกค้าไว้ ก่อนพิมพ์ส่ง
ใบเสนอราคาที่สร้างอัตโนมัติ — แบ่ง section ตาม Zone
