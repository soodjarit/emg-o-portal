ภาพรวม · การขายหินแบบล็อตคืออะไร

ไม่ใช่หินทุกชนิดขายแบบนับแผ่น — บางชนิดตั้งราคาเป็น "ตารางเมตรต่อล็อต" แทน

i
ขายแบบล็อตต่างจากขายแบบเลือกทีละแผ่นอย่างไร
วัสดุบางชนิด (เช่น Bianco Perla) นำเข้ามาเป็นล็อตใหญ่ ไม่ได้ตัดแยกเป็นแผ่นไว้ล่วงหน้า — ระบบจึงให้เลือกขายตรงจากล็อตนั้นแทน โดยระบุจำนวนตารางเมตรที่ต้องการขายได้อย่างอิสระ ไม่จำเป็นต้องขายทั้งล็อตในครั้งเดียว เหมาะกับวัสดุที่นิยมซื้อขายเป็นปริมาณมากกว่านับเป็นแผ่น
1. เปิดใบสั่งขาย + เลือกสินค้า→ 2. เลือกล็อตที่จะขาย→ 3. ยืนยันการขาย→ 4. ส่งของ→ ใบแจ้งหนี้→ รับเงิน
หมายเหตุ: ไม่ว่าจะขายแบบล็อต แบบทั้งก้อน หรือแบบเลือกทีละแผ่น หากวัสดุนั้นอยู่คนละบริษัทกับใบขาย ระบบจะดำเนินการข้ามบริษัทให้อัตโนมัติเหมือนกันทุกรูปแบบการขาย
เอกสารนี้เริ่มนับจากมีล็อตหินพร้อมขายอยู่แล้วในสต็อก — ขั้นตอนสั่งซื้อและรับหินเข้าคลังดูรายละเอียดที่เอกสาร Ensure Supply — รับหินเข้าคลัง
ขั้นตอนที่ 1 · เปิดใบสั่งขาย

เลือกลูกค้า แล้วเพิ่มสินค้าในกลุ่มที่ขายแบบล็อต

  • 1เปิดใบเสนอราคาใหม่จากเมนู Sales
  • 2เลือกลูกค้า
  • 3เพิ่มสินค้าลงในรายการ แล้วเลือก "Bianco Perla Marble Slab" ซึ่งเป็นวัสดุที่ขายแบบล็อต
  • 4บรรทัดสินค้าจะแสดงลิงก์ Select Lot Stock แทนที่จะเป็น Select Slabs ตามปกติ
ลิงก์ที่ปรากฏในคอลัมน์ Block / Lot จะเปลี่ยนตามประเภทวัสดุที่เลือกโดยอัตโนมัติ — Select Lot Stock หมายถึงขายแบบล็อต ส่วน Select Slabs หมายถึงขายแบบเลือกทีละแผ่นตามปกติ
ผลลัพธ์: ใบเสนอราคาใหม่ พร้อมสินค้า Bianco Perla และลิงก์ Select Lot Stock ที่ปรากฏขึ้นอัตโนมัติ
ขั้นตอนที่ 2 · เลือกล็อตที่จะขาย

เลือกล็อต ระบบแสดงจำนวนตารางเมตรที่เหลือให้ทันที แล้วระบุจำนวนที่ต้องการขาย

  • 1เลือกล็อตที่ต้องการขาย — ระบบแสดงเฉพาะล็อตที่มีสต็อกพร้อมขายจริงเท่านั้น
  • 2ระบบแสดงจำนวนตารางเมตรที่เหลืออยู่ในล็อตนั้นโดยอัตโนมัติ (ตัวอย่างนี้เหลือ 4.00 ตร.ม. จากทั้งล็อต 6.00 ตร.ม.)
  • 3ระบุจำนวนตารางเมตรที่ต้องการขายตามความต้องการของลูกค้า โดยไม่จำเป็นต้องขายทั้งล็อต (ตัวอย่างนี้ขาย 1.50 ตร.ม.)
  • 4ยืนยันการเลือก
ผลลัพธ์: ล็อต BP-B-0001 มีสต็อกเหลือ 4.00 ตร.ม. — เลือกขาย 1.50 ตร.ม.

ผลลัพธ์: หน้าจอแจ้งให้ยืนยันล็อตก่อนดำเนินการต่อ
