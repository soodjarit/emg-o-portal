ภาพรวม · Select Lot Stock คืออะไร

ไม่ใช่หินทุกชนิดขายแบบนับแผ่น — บางชนิดตั้งราคาเป็น "ตารางเมตรต่อล็อต" แทน

i
Mode 2 ต่างจาก Mode ปกติ (Select Slabs) ยังไง
วัสดุแต่ละชนิดตั้งค่า Pricing Mode ไว้ที่ระดับ Material — ถ้าเป็น Lot (เช่น Bianco Perla) ระบบจะไม่สร้าง stone.slab รายแผ่นให้เลือกทีละแผ่นแบบปกติ แต่ให้เลือก Lot (Block/Bundle) แล้วพิมพ์จำนวนตารางเมตรที่จะขายจากล็อตนั้นได้อิสระ (ขายบางส่วนได้ ไม่ต้องขายทั้งล็อต) เหมาะกับหินที่ import มาเป็นล็อตใหญ่ ไม่ได้ตัดแยกแผ่นไว้ล่วงหน้า
1. เปิด SO + เลือกสินค้า→ 2. Select Lot Stock→ 3. ยืนยัน SO→ 4. ส่งของ→ Invoice→ รับเงิน
หมายเหตุ: Mode 2 (Lot), Mode 1 (Select Block — ขายทั้งก้อน), และโหมดปกติ (Select Slabs — เลือกทีละแผ่น) ใช้กลไก intercompany เดียวกันทั้งหมดถ้าล็อต/บล็อกนั้นเป็นของอีกบริษัท — ดูรายละเอียดใน deck "E2E — Intercompany Trade" แยกต่างหาก
ขั้นตอนที่ 1 · เปิด Sale Order

เลือกลูกค้า แล้วเพิ่มสินค้าที่เป็น Lot mode

  • 1Sales → New เปิด Quotation ใหม่
  • 2เลือกลูกค้า
  • 3Add a product → เลือก "Bianco Perla Marble Slab" (วัสดุที่ตั้ง Pricing Mode = Lot)
  • 4บรรทัดสินค้าจะโชว์ลิงก์ Select Lot Stock แทนที่จะเป็น Select Slabs ปกติ — สังเกตความต่างตรงนี้
ลิงก์ที่ขึ้นในคอลัมน์ "Block / Lot" คือตัวบอกว่าสินค้านี้เป็น Lot mode — ถ้าเห็น "Select Slabs" แทน แปลว่าสินค้าตัวนั้นเป็นโหมดนับแผ่นปกติ ไม่ใช่ Mode 2
SO ใหม่ พร้อมสินค้า Bianco Perla + ลิงก์ Select Lot Stock
ขั้นตอนที่ 2 · Select Lot Stock Wizard

เลือกล็อต ระบบโชว์ Sq.Mt. ที่เหลือให้ทันที แล้วพิมพ์จำนวนที่จะขาย

  • 1เลือก Lot (Block/Bundle) — เห็นล็อตที่มีสต็อกจริงเท่านั้น
  • 2"Remaining Sq.Mt. (Lot)" โชว์อัตโนมัติ (ตัวอย่างนี้ = 4.00 ตร.ม. เหลือจากทั้งล็อต 6.00)
  • 3พิมพ์ Quantity to Sell ตามที่ลูกค้าต้องการ — ไม่ต้องขายทั้งล็อต (ตัวอย่างนี้ขาย 1.50 ตร.ม.)
  • 4Confirm Selection

Validate ตรงๆ แล้วเจอ Error — "Scan verification failed"

สิ่งที่เจอ
กด Validate แล้วระบบไม่ยอมให้ผ่าน ขึ้น "Invalid Operation — Scan verification failed for: BP-B-0001-LOT" ทั้งที่ล็อต/จำนวนถูกต้องอยู่แล้ว
สาเหตุ: ระบบ requires การ "scan" ยืนยัน Lot/Serial ก่อน Validate เสมอ แม้ว่า Lot ที่ถูกต้องจะถูกกำหนดไว้ล่วงหน้าโดยอัตโนมัติแล้วก็ตาม (Odoo เตรียม quantity ให้ แต่ยังไม่ mark ว่า "scanned/picked") — เจอทั้งใน Mode ปกติ (per-slab) และ Mode 2 (lot) เหมือนกัน ไม่ใช่บั๊กเฉพาะ Mode นี้
Error จริงที่เจอบน production
✅ วิธีแก้ · ทำตามทุกครั้งก่อน Validate

คลิก "Details" ที่บรรทัดสินค้า แล้วเลือก Lot ในช่อง Scanned Serial

  • 1ที่หน้า Delivery คลิก Details ตรงบรรทัดสินค้า
  • 2เห็นคอลัมน์ "Scanned Serial" ว่างอยู่ — ทั้งที่ "Pick From" ระบุ Lot ถูกต้องแล้ว
  • 3คลิกช่อง Scanned Serial แล้วพิมพ์/เลือกชื่อ Lot เดียวกัน (เช่น BP-B-0001-LOT)
  • 4Save → กลับไป Validate อีกครั้ง — ผ่านทันที
จำไว้: ทุกครั้งที่เจอ "Scan verification failed" ให้เปิด Details แล้วกรอก Scanned Serial ด้วยชื่อ Lot เดิม ไม่ต้องเปลี่ยนอะไรอย่างอื่น

Cheat Sheet — Select Lot Stock (Mode 2)

  • 1ใช้ได้เฉพาะวัสดุที่ตั้ง Pricing Mode = Lot ที่ระดับ Material เท่านั้น — สังเกตจากลิงก์ "Select Lot Stock" บนบรรทัดสินค้า
  • 2ขายบางส่วนจากล็อตได้อิสระ — Wizard โชว์ "Remaining Sq.Mt." ให้เช็คก่อนพิมพ์จำนวนเสมอ
  • 3ทุกครั้งที่ Validate Delivery แล้วเจอ "Scan verification failed" — เปิด Details บนบรรทัดสินค้า แล้วกรอก Scanned Serial ด้วยชื่อ Lot เดิมก่อนเสมอ (เจอทั้ง Mode ปกติและ Mode 2)
  • 4หลังจากผ่าน Wizard แล้ว ขั้นตอน Confirm → Delivery → Invoice → Payment เดินเหมือนทุก Mode อื่นทุกประการ
