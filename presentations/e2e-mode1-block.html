ภาพรวม · สิ่งที่จะโชว์ลูกค้าวันนี้

ขายก้อนหินทั้งก้อนได้ในคลิกเดียว — แม้ก้อนนั้นจะอยู่คนละบริษัทกับใบขาย

i
Mode 1 คืออะไร ต่างจาก Cut to Order / Select Slabs ยังไง
บางลูกค้าต้องการซื้อก้อนหินทั้งก้อน ไม่ตัดแบ่งขายเป็นแผ่น (เช่น เอาไปแปรรูปเอง) ระบบมีปุ่ม "Sell Whole Block" บนบรรทัดขาย — เลือกก้อนที่จะขาย ระบบตั้งจำนวนขาย = CBM ที่เหลือทั้งหมดให้อัตโนมัติ (ขายเกลี้ยงก้อน ไม่แบ่งขาย) เนื่องจากก้อนหินเก็บสต็อกร่วมกันได้ทั้ง 2 บริษัท (Empire Granite/Empire Stone) ถ้าก้อนที่เลือกอยู่คนละบริษัทกับใบขาย ระบบจะ auto สร้างเอกสารซื้อ-ขายภายในให้เองทันที
1. เปิด SO + เลือก Block→ 2. Sell Whole Block→ 3. Confirm SO→ 4. Intercompany Trade→ 5. ส่งของ (Drop-ship)→ 6. Invoice→ 7. รับชำระเงิน
มี 1 จุดที่อยากให้ยืนยันกับลูกค้าวันนี้ — พฤติกรรม auto intercompany + drop-ship ตอนก้อนหินอยู่คนละบริษัทกับใบขาย (สไลด์ที่ 5) ว่าตรงกับที่ลูกค้าคาดหวังมั้ย เก็บไว้เป็นสไลด์เฉพาะให้ถามตรงจุด
ขั้นตอนที่ 1 · เปิดใบขาย

เปิด Sale Order → เลือกสินค้า "ก้อน" (Block) → ปุ่ม "Sell Whole Block" โผล่ขึ้นมาเอง

  • 1Sales → New → เลือกลูกค้า
  • 2"Add a product" → เลือกสินค้าก้อน (เช่น "Emperador Grey Light Marble Block" — คนละ SKU กับสินค้าแผ่น) → Save
  • 3ระบบโชว์ปุ่ม "Sell Whole Block" บนบรรทัดขายทันที — รู้เองว่าสินค้านี้เป็น Block-tracked
  • 4กดปุ่มนี้เพื่อเลือกว่าจะขายก้อนไหน
Goal
ไม่ต้องตั้งค่าอะไรเพิ่ม ระบบแยกสินค้า "ก้อน" กับ "แผ่น" เป็นคนละ SKU ให้ชัดเจนอยู่แล้วตั้งแต่ต้น
ข้อควรระวัง
ต้อง Save บรรทัดขายก่อน ปุ่มถึงจะโผล่ขึ้นมาให้กด (เหมือนกันกับ Cut to Order)
S108361 — บรรทัดขายพร้อมปุ่ม "Sell Whole Block"
ขั้นตอนที่ 2 · เลือกก้อนที่จะขาย

Select Block wizard — เลือกก้อน ระบบโชว์ CBM คงเหลือให้ดูก่อนยืนยัน

  • 1Dropdown "Block" กรองให้อัตโนมัติเฉพาะก้อนของ material เดียวกัน กับสินค้าที่เลือก (เช่น Emperador Grey Light เท่านั้น) — กรองข้ามทั้ง 2 บริษัทด้วย ไม่ได้ล็อคแค่บริษัทที่เปิดใบขาย
  • 2เลือกก้อนที่ต้องการ (ตัวอย่าง EMG-B-0008) → ฟิลด์ "Remaining CBM" โชว์ปริมาณคงเหลือจริงให้ดูก่อนตัดสินใจ (0.90 m³)
  • 3กด "Confirm Selection"
Goal
เห็น CBM คงเหลือจริงก่อนกด confirm เสมอ ป้องกันขายเกินสต็อกที่มีจริง
ข้อควรระวัง
โหมดนี้ ขายทั้งก้อนเท่านั้น ไม่แบ่งขายบางส่วน — ถ้าลูกค้าต้องการซื้อบางส่วน ต้องใช้ Mode 2 (Select Lot Stock) แทน
Select Block — EMG-B-0008 เหลือ 0.90 m³
ขั้นตอนที่ 3 · ยืนยันใบขาย

จำนวนขาย = CBM เต็มก้อนอัตโนมัติ → กด Confirm → Delivery สร้างให้เอง

  • 1บรรทัดขายเติม Quantity = 0.90 m³ ให้อัตโนมัติ (เท่ากับ CBM เต็มของก้อนที่เลือก) — ไม่ต้องพิมพ์เอง
  • 2คอลัมน์ "Block / Lot" โชว์ชื่อก้อนที่ผูกไว้ (EMG-B-0008) ให้เห็นตลอดว่าใบขายนี้ผูกกับก้อนไหน
  • 3กด "Confirm" — สถานะเปลี่ยนเป็น Sales Order, Delivery smart button ขึ้นมาทันที
Goal
พนักงานไม่ต้องคำนวณหรือพิมพ์จำนวนเอง ลดความเสี่ยงขายผิดจำนวน
S108361 — Confirmed, qty 0.90 m³, Delivery (1)
🔵 จุดที่อยากให้ลูกค้ายืนยันดีไซน์

ก้อนนี้เป็นของ Empire Stone แต่ใบขายเปิดฝั่ง Empire Granite — ระบบ auto สร้างเอกสารซื้อ-ขายภายในให้เอง

Delivery ฝั่ง EG (ผู้เปิดใบขาย) — ถูก "Cancelled" อัตโนมัติ เพราะของจริงไม่ได้อยู่ที่นี่
Delivery จริง (ESWH/OUT/00015) — ส่งตรงจากคลัง Empire Stone ถึงลูกค้าเลย
  • 1ของจริงไม่ต้องย้ายเข้าคลัง EG ก่อน — ระบบส่งตรง (Drop-ship) จากคลังของบริษัทที่ของอยู่จริง (ES) ไปหาลูกค้าเลย ประหยัดเวลา/ค่าขนส่งซ้ำซ้อน
  • 2เบื้องหลังสร้างเอกสารบัญชีคู่กันให้เอง — Internal SO (ES ขายให้ EG) + Internal PO (EG ซื้อจาก ES) พร้อม draft Invoice/Bill ให้ accountant ตรวจสอบก่อน post เอง (ไม่ auto post) — คำถามให้ถามลูกค้า: พฤติกรรมนี้ตรงกับที่ลูกค้าต้องการมั้ย หรืออยากให้แต่ละบริษัทขายแค่ของบริษัทตัวเองเท่านั้น (ปิด auto-trade)?
ขั้นตอนที่ 4 · ส่งของสำเร็จ

Validate ผ่านทันที — ไม่ต้องกรอก Serial (ก้อนหินไม่ track แบบ serial เหมือนแผ่น)

  • 1เปิด Internal SO ฝั่ง Empire Stone → Delivery smart button → เจอ ESWH/OUT/00015
  • 2กด "Validate" ได้ทันที — สถานะ Ready → Done
  • 3ต่างจาก Mode 3 (แผ่นตัดตามสั่ง) ที่ต้องกรอก "Scanned Serial" ก่อน — ก้อนหิน (Block) เป็นสินค้า lot-tracked แบบ CBM ไม่ใช่ serial ต่อชิ้น จึงไม่เจอ guard เดียวกัน
Goal
ขั้นตอนส่งของสั้นกว่าโหมดขายแผ่น — เหมาะกับก้อนที่ลูกค้าซื้อไปแปรรูปเอง ไม่ต้องยุ่งกับ serial ต่อชิ้น
ESWH/OUT/00015 — Done
ขั้นตอนที่ 5 · ออกใบแจ้งหนี้ (ฝั่งลูกค้าจริง)

กลับมาใบขายจริง (ฝั่ง EG) → Create Invoice ให้ลูกค้าตามปกติ

  • 1Invoice ฉบับนี้ออกจาก ใบขายจริงของลูกค้า (S108361) — คนละใบกับ draft invoice ภายในระหว่าง EG/ES ที่เพิ่งเห็น
  • 2กด "Create Invoice" → "Regular invoice" → "Create Draft" เหมือนใบขายทั่วไป ไม่มีขั้นตอนพิเศษเพิ่ม
Goal
ฝั่งลูกค้าไม่เห็น/ไม่ยุ่งกับความซับซ้อนของ intercompany เลย — ได้ใบแจ้งหนี้ปกติ 1 ใบ ราคาต่อ CBM ตามที่ตกลงกับลูกค้าโดยตรง
Draft Invoice จาก S108361 — 0.90 m³ × 3,500 บาท
ขั้นตอนที่ 6 · ยืนยันใบแจ้งหนี้

ขั้นตอนที่ 7 · รับชำระเงิน

กด "Pay" → ยืนยัน → เสร็จในคลิกเดียว เหมือนใบขายทั่วไปทุกจุด

  • 1จากหน้า Invoice ที่ Posted แล้ว กดปุ่ม "Pay"
  • 2Wizard "Register Payment" เติม Journal/Amount เต็มจำนวนให้อัตโนมัติ (3,370.50 บาท)

ฝั่งลูกค้าใช้ flow เดียวกับการขายแผ่นทุกประการ — ความซับซ้อนของ intercompany อยู่หลังบ้านทั้งหมด

สรุปด่วน · ก่อนขึ้นพรีเซนต์จริง

สิ่งที่ต้องอธิบาย + คำถามที่ต้องถามลูกค้า

  • 1Mode 1 ขายทั้งก้อนเท่านั้น ไม่แบ่งขาย — ถ้าลูกค้าต้องการซื้อบางส่วนของก้อน ต้องใช้ Mode 2 (Select Lot Stock) แทน
  • 2🔵 ถามลูกค้า: พอใจกับพฤติกรรม auto intercompany + drop-ship ตอนก้อนอยู่คนละบริษัทมั้ย (สไลด์ 5) — หรืออยากให้ระบบจำกัดไม่ให้ขายข้ามบริษัทเลย
  • 3ใบขายจริงของลูกค้าเห็นแค่ใบขาย/ใบแจ้งหนี้ปกติ 1 ชุด — เอกสารซื้อ-ขายภายในระหว่าง EG/ES (Internal SO/PO + draft invoice/bill) เป็นเรื่องหลังบ้านที่ accountant จัดการ ไม่กระทบประสบการณ์ลูกค้า
  • 4Drop-ship ประหยัดเวลาจริง — ของไม่ต้องย้ายเข้าคลัง EG ก่อนแล้วค่อยส่งต่อ ส่งตรงจากคลังที่ของอยู่จริงถึงลูกค้าเลย
