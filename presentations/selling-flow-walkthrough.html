EMG-O Manual ch.4-6 · Select Slabs → Confirm → Invoice → Delivery
ภาพรวม · สิ่งที่จะโชว์ลูกค้าวันนี้

1 วงจรต่อเนื่อง จากใบเสนอราคา ถึงส่งของถึงมือลูกค้า

i
ทำไมควรโชว์ครบวงจรในครั้งเดียว
ลูกค้าจะเห็นว่าทุกขั้นตอน — เลือกแผ่นจริงจากสต็อก, ตั้งราคา, ออกใบแจ้งหนี้, จนถึงส่งของ — เชื่อมกันเป็นเรื่องเดียว ไม่มีจุดไหนต้องกรอกซ้ำหรือกระทบยอดเอง ทุกตัวเลขตรงกันตลอดสาย
1. เพิ่มสินค้าในใบเสนอราคา→ 2. Select Slabs→ 3. Confirm SO→ 4. Create Invoice→ 5. ส่งของ + สแกน→ 6. เซ็นรับ
มีจุดต้องระวัง 3 จุด ระหว่างทางที่พรีเซนเตอร์ควรรู้ล่วงหน้า (สรุปรวมไว้ในสไลด์สุดท้าย) — จะได้อธิบายลูกค้าได้ทันทีว่าเป็นเรื่องปกติ ไม่ใช่ระบบมีปัญหา
ขั้นตอนที่ 1 · เพิ่มสินค้าในใบเสนอราคา

เลือกสินค้าเป็นวัสดุหิน — ปุ่ม "Select Slabs" จะโผล่ให้เองอัตโนมัติ

  • 1เปิด Sales Order ใหม่ ใส่ลูกค้า
  • 2"Add a product" เลือกสินค้าที่เป็นวัสดุหิน (เช่น "Emperador Grey Light Marble Slab")
  • 3ระบบรู้เองว่าเป็นวัสดุหิน แสดงปุ่ม "Select Slabs" ต่อท้ายชื่อสินค้าในบรรทัดทันที — ไม่ต้องตั้งค่าอะไรเพิ่ม
จุดขาย: ระบบแยกอัตโนมัติว่าสินค้าไหนต้องเลือกแผ่นจริง สินค้าไหนเป็นค่าแรง/บริการทั่วไป — พนักงานไม่ต้องจำเองว่าบรรทัดไหนต้องทำอะไรต่อ
ขั้นตอนที่ 2 · เลือกแผ่นจริงจากสต็อก

กด "Select Slabs" — เห็นเฉพาะแผ่นที่มีอยู่จริง พร้อมขาย

  • 1คลิก "Select Slabs" → เปิด wizard เลือกแผ่น
  • 2"Add a line" → เลือก Bundle — ระบบกรองให้เห็นเฉพาะแผ่นสถานะ Available ของสินค้านั้น (รวมทุกคลัง/ข้ามบริษัทที่มีสิทธิ์เห็น)
  • 3เลือกแผ่นที่ต้องการ (เลือกได้หลายแผ่น) → กด "Confirm Selection"
  • 4จำนวนและราคาต่อหน่วยบน Order Line อัปเดตให้อัตโนมัติทันที
⚠️ ก่อนขายทุกครั้ง เช็ค "Sales Price / Sq.Mt." ที่หน้า Bundle ก่อนเสมอ
ราคาต่อหน่วยที่ขึ้นบน Order Line คำนวณจากค่านี้ × พื้นที่จริงของแผ่น — ถ้ายังไม่กรอกไว้ (0.00) ราคาที่ได้จะเป็น 0.00 ด้วย

ขั้นตอนที่ 4 · ออกใบแจ้งหนี้

Create Invoice → Regular Invoice → Confirm

  • 1จากหน้า SO ที่ Confirm แล้ว กด "Create Invoice"
  • 2เลือก "Regular Invoice" → "Create and View Invoice"
  • 3ตรวจราคา/ยอดรวมอีกครั้งบนหน้า Draft Invoice
  • 4กด Confirm เพื่อ Post ใบแจ้งหนี้เข้าระบบบัญชี
⚠️ ครั้งแรกที่ใช้บัญชีธนาคารบริษัทกับใบแจ้งหนี้ จะมีเตือน "not trusted"
เป็นระบบป้องกันการโกงของ Odoo เอง ไม่ใช่บั๊ก — แก้ครั้งเดียว: Bank Settings → toggle เป็น "Trusted" → Save → กลับมา Confirm ใหม่ ครั้งต่อไปจะไม่เตือนอีก
ขั้นตอนที่ 5 · ส่งของ (Delivery)

สแกน/เลือกยืนยัน Lot ให้ตรงก่อน Validate เสมอ

  • 1เปิด Delivery Order (smart button "Delivery" บนหน้า SO)
  • 2ที่บรรทัดสินค้า กด "Details" → เจอช่อง "Scanned Lot"
  • 3สแกนด้วยเครื่องจริง (ถ้ามี) หรือเลือกจาก dropdown ให้ตรงกับ Lot/Serial ของแผ่นจริงที่หยิบ
  • 4กด Validate — สต็อกย้ายจาก Stone Hold → Customer, แผ่นเปลี่ยนเป็น Sold
⚠️ ข้ามขั้นตอนนี้ไม่ได้ — ระบบบล็อกทันที
ถ้า Scanned Lot ไม่ตรงกับ Lot จริง (หรือไม่ได้กรอก) กด Validate จะขึ้น "Scan verification failed" — ป้องกันหยิบแผ่นผิดส่งให้ลูกค้า เป็นฟีเจอร์ตั้งใจ (ADR-009)
ขั้นตอนที่ 6 · เซ็นรับของ (ไม่บังคับ)

Proof of Delivery พร้อมลายเซ็นจริงของลูกค้า

6
ทางเลือกเสริมที่ลูกค้ามักชอบเห็น
ในแท็บ "Customer Signature" กรอกชื่อผู้รับ ("Received By") แล้วให้ลูกค้าเซ็นบนหน้าจอ (นิ้ว/ปากกา/เมาส์ก็ได้) ระบบ stamp วันเวลาให้อัตโนมัติ จากนั้นพิมพ์ "Proof of Delivery" เป็น PDF สรุปสินค้า+Serial+ลายเซ็นจริง เก็บเป็นหลักฐานได้ทันที
หมายเหตุ: การเซ็นเป็น optional ไม่บล็อกการ Validate — จะเซ็นก่อนหรือหลังก็ได้ตามความสะดวกหน้างาน
สรุปด่วน · ก่อนขึ้นพรีเซนต์จริง

3 จุดห้ามลืม ระหว่างพรีเซนต์สด

  • 1เช็ค Sales Price / Sq.Mt. ของทุก Bundle ที่จะใช้เดโม่ไว้ล่วงหน้า — ไม่งั้นราคาตอน Select Slabs จะขึ้น 0.00 ต่อหน้าลูกค้า
  • 2บัญชีธนาคารที่จะใช้ในเดโม่ ตั้ง "Trusted" ไว้ล่วงหน้า (Accounting → Bank Accounts) — กันไม่ให้เจอป็อปอัพเตือนกลางที่พรีเซนต์
  • 3อย่าลืมกรอก "Scanned Lot" ก่อนกด Validate ที่ Delivery Order เสมอ — ถ้าลืม ระบบจะบล็อกทันที ให้อธิบายลูกค้าได้เลยว่านี่คือมาตรการกันหยิบแผ่นผิด ไม่ใช่ระบบค้าง
