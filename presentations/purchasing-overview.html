รายละเอียดขั้นตอน

  • 1Purchase → New → เลือก Block Product ของวัสดุนั้น → กรอก Quantity เป็นคิว + ราคาต่อคิว → Confirm Order

  • 3ช่อง Purchase Order Line เลือก PO ที่เพิ่ง Confirm → Supplier/Total CBM เติมอัตโนมัติ → กรอก Thickness เอง

สถานะปัจจุบัน
ทั้ง 2 บริษัท (Empire Granite, Empire Stone) ตั้งค่า one-step validation — คนที่มีสิทธิ์ Confirm PO ยืนยันซื้อได้เลยไม่ว่าวงเงินเท่าไหร่ ไม่มีคนที่สองอนุมัติ และไม่มี module "ใบขอซื้อ" (Purchase Request แยกจาก PO) ติดตั้งอยู่
ถ้าต้องการภายหลัง — มี 2 ทางเลือก
ทางเลือกรายละเอียดขนาดงาน
เปิด 2-step approvalตั้งวงเงินที่ต้องขออนุมัติ ใช้ของที่ Odoo มีอยู่แล้วเล็ก — ไม่ต้องเพิ่ม module
ติดตั้ง module ใบขอซื้อ (PR)แยกขั้นตอน "ขอซื้อ" ออกจาก PO เป็นเอกสารคนละใบใหญ่กว่า — ต้องออกแบบ workflow ใหม่ทั้งหมด
