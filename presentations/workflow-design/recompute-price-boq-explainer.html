Root Cause — โค้ดจริง

action_recompute_boq_price() ไม่รู้ว่า qty ถูกเปลี่ยนไปแล้ว

class SaleOrderLine(models.Model):
  def action_recompute_boq_price(self):
    total_sqmt = sum(self.stone_slab_ids.mapped('slab_sqmt'))
    # ตั้งใจให้เป็นราคา "เต็ม" สำหรับตอน qty=1 (ตอน BOQ เพิ่งสร้าง)
    self.price_unit = self.boq_line_id.rate_id.price_unit * total_sqmt
    # แต่ qty ถูก hold_for_sale_line() เปลี่ยนเป็นจำนวน Slab ไปแล้วตั้งแต่ก่อนหน้านี้
    # Odoo subtotal = price_unit × qty → คูณซ้ำด้วยจำนวน Slab อีกรอบ
สรุป bug: สูตรนี้ถูกต้องเฉพาะตอน qty=1 เท่านั้น (สภาพตอน BOQ เพิ่ง generate) แต่ ณ จุดที่ปุ่มนี้จะโชว์ให้กดได้จริง (boq_line_id ตั้งแค่หลัง Select Slabs/Cut Order สำเร็จแล้ว) qty มักไม่ใช่ 1 อีกต่อไป — ปุ่มจึงเขียน "ราคาเต็ม" ทับลงในช่อง "ราคาต่อหน่วย" ทั้งที่ qty มากกว่า 1 แล้ว
ข้อเสนอแก้ไข

หาร qty ออกก่อน — ให้ price_unit × qty กลับมาเท่ากับยอดที่ quote จริง

  def action_recompute_boq_price(self):
    self.ensure_one()
    total_sqmt = sum(self.stone_slab_ids.mapped('slab_sqmt'))
    if not total_sqmt:
      raise UserError(...)
    total_qty = self.product_uom_qty or 1
    self.price_unit = self.boq_line_id.rate_id.price_unit * total_sqmt / total_qty
