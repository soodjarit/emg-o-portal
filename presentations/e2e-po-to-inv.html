ภาพรวม · สิ่งที่จะโชว์ลูกค้าวันนี้

1 Analytic Account เดียว ตามรอยได้ทุกขั้น — ซื้อ, ผลิต, ขาย

i
ทำไมต้องมี Analytic Account
ปกติต้นทุนซื้อหินอยู่ฝั่ง Purchase ส่วนรายได้ขายอยู่ฝั่ง Sales — คนละหน้าจอ คนละรายงาน ถ้าไม่มีตัวเชื่อม จะไม่รู้เลยว่าหินก้อนนี้ "คุ้มทุน" หรือยัง ระบบให้สร้าง Analytic Account 1 ตัว (ในที่นี้ตั้งชื่อ "AAA") แล้วผูกเข้ากับ Bundle ตั้งแต่ต้นทาง — จากนั้นทุกเอกสารที่เกี่ยวข้อง (PO Line, Vendor Bill, SO Line, Invoice) จะแปะป้ายให้อัตโนมัติทั้งสาย
1. สร้าง Analytic Account "AAA"→ 2. Purchase Order→ 3. Bundle + ผูก AAA→ 4. ตัดแผ่น (มือ)→ 5. Select Slabs→ 6. Confirm SO→ 7. Invoice→ 8. Vendor Bill
เดโม่นี้เจอบั๊กจริง 2 จุดระหว่างเดิน flow (ราคาขึ้น 0.00 หลัง Select Slabs, และ error "lot incompatible") — เก็บไว้สอนเป็นจุดห้ามลืมในสไลด์เฉพาะ เพราะเป็นเรื่องที่พนักงานจริงมีโอกาสเจอเหมือนกัน
ขั้นตอนที่ 1 · ตั้งค่าก่อนเริ่ม

สร้าง Analytic Account "AAA" — บัญชีกลางที่จะผูกทุกขั้นตอน

  • 1ไปที่ Invoicing → Configuration → Analytic Accounts → New
  • 2ช่อง Analytic Account — พิมพ์ชื่อโปรเจกต์ (ตัวอย่าง: "AAA")
  • 3ช่อง Plan — เลือก "Project" (ค่า default ของระบบนี้)
  • 4เช็คช่อง Company มุมขวา (ระบบผูกให้อัตโนมัติตาม Company ที่ Active อยู่ตอนนั้น) → Save
Goal
มีจุดศูนย์กลาง 1 จุด ไว้รวมต้นทุน+รายได้ของหินล็อตนี้ทั้งหมด
ข้อควรระวัง
ต้องเช็ค Company ก่อนกดสร้างเสมอ — สร้างผิด Company จะมีปัญหาตอนออกบิลข้ามบริษัททีหลัง
กรอกชื่อ "AAA" + เลือก Plan = Project — จุดที่ Input ข้อมูล
ขั้นตอนที่ 2 · นำเข้าหิน (Purchase)

สร้าง Purchase Order ซื้อก้อนหินจริงจาก Vendor

  • 1Purchase → New → เลือก Vendor (ตัวอย่าง: Demo Supplier - Global Stone Quarry)
  • 2"Add a product" → เลือก Block Product ของวัสดุนั้น (เช่น "Rosa Portogallo Granite Block") — ต้องเป็น Block ไม่ใช่ Slab
  • 3กรอก Quantity เป็นคิว (m³) ที่ซื้อจริง (ตัวอย่าง 5 m³) + Unit Price ต่อคิว (8,000/m³)
  • 4Save → Confirm Order — PO เปลี่ยนเป็น Purchase Order ยืนยันแล้ว
Goal
บันทึกต้นทุนซื้อจริงเข้าระบบ พร้อมผูก Vendor — เป็นฐานให้ Bundle มาอ้างอิงต่อ
ข้อควรระวัง
ต้อง Confirm Order ให้เสร็จก่อนเสมอ — Bundle จะหา PO Line เจอเฉพาะ PO ที่ Confirm แล้วเท่านั้น
PO P00062 ยืนยันแล้ว — 5 m³ × 8,000 = 40,000 บาท
ขั้นตอนที่ 3 · รับสต็อกเข้าคลัง + ผูก Analytic

สร้าง Bundle ผูก PO Line + ตั้ง Analytic Account = AAA ตรงนี้

  • 1Stone Slab → Bundles → New → เลือก Material → กรอก Purchase Order Line (ระบบกรองให้เหลือเฉพาะ PO ที่ Confirm แล้วของวัสดุนี้)
  • 2Supplier + Total CBM กรอกให้อัตโนมัติจาก PO — เหลือกรอก Thickness (M) เอง
  • 3เลือก Warehouse + กรอก Sales Price / Sq.Mt. (สำคัญมาก ดูสไลด์ถัดไป)
  • 4ช่อง Analytic Account — เลือก "AAA" ที่สร้างไว้ → Save
Goal
ระบบแปะป้าย AAA ลง PO Line ให้อัตโนมัติทันที — Vendor Bill ที่จะสร้างจาก PO นี้จะติดป้ายมาด้วยเลย
ข้อควรระวัง
ต้องเลือก Finish (Polished/Honed ฯลฯ) ให้ตรงกับสินค้าที่จะขายจริงตั้งแต่ตอนนี้ — ถ้าปล่อยว่างแล้วมาแก้ทีหลัง แผ่นที่ตัดไปแล้วจะหาไม่เจอตอน Select Slabs (ล็อตหินผูกกับ variant ตายตัว)
กรอก Warehouse, Sales Price/Sq.Mt., Analytic Account = AAA — จุดที่ Input ข้อมูล
ขั้นตอนที่ 4 · ตัดแผ่น (Manual Input Slab)

Add a line ทีละแผ่น — กรอกขนาดจริงด้วยมือ (Slab L, Slab H)

  • 1ในฟอร์ม Bundle → แท็บ Slabs → "Add a line"
  • 2กรอก Slab L (M) และ Slab H (M) ตามขนาดจริงที่วัดได้หน้างาน — ระบบคำนวณ Slab Sqmt ให้อัตโนมัติ
  • 3ทำซ้ำทีละแผ่น (ตัวอย่าง: แผ่น 1 = 3.00×1.60 m, แผ่น 2 = 2.80×1.60 m) → Save
  • 4ระบบสร้าง Serial Number เฉพาะแผ่น + หัก CBM จากก้อนหิน + ตั้งสถานะ Available ให้อัตโนมัติ
Goal
หินก้อนดิบกลายเป็นแผ่นพร้อมขายจริง แต่ละแผ่นมีเลขประจำตัวแยกกัน สแกนยืนยันได้ตอนส่งของ
ข้อควรระวัง
ขนาดแผ่นเป็นการกรอกมือทั้งหมด ระบบไม่ได้วัดให้ — พนักงานต้องวัดจริงหน้างานให้แม่นก่อนกรอก เพราะ Sqmt/ราคาขายคำนวณต่อจากตัวเลขนี้โดยตรง
2 แผ่นบันทึกแล้ว — Total Sqmt คำนวณอัตโนมัติจากขนาดที่กรอก
ขั้นตอนที่ 5 · ขาย — เลือกแผ่นจริงจากสต็อก

สร้าง Sale Order → "Select Slabs" → เลือกแผ่นจริงที่เพิ่งตัด

  • 1เปิด Sale Order ใหม่ ใส่ลูกค้า → Add a product เลือกวัสดุหินชนิดเดียวกับ Bundle
  • 2คลิก "Select Slabs" → wizard เปิดขึ้น → "Add a line"
  • 3ระบบกรองให้เห็นเฉพาะแผ่นสถานะ Available ของ Bundle นี้ — ติ๊กเลือกแผ่นที่ต้องการ (เลือกได้หลายแผ่น)
  • 4กด Select → Confirm Selection — Quantity บน Order Line อัปเดตอัตโนมัติ
Goal
ผูกแผ่นจริงจากสต็อกเข้ากับใบขาย ไม่ใช่พิมพ์จำนวนลอยๆ — กันขายเกินสต็อกจริง
ข้อควรระวัง
Unit Price ควรดึงจาก Sales Price/Sq.Mt. ของ Bundle อัตโนมัติ — แต่ในเดโม่นี้ขึ้น 0.00 ทั้งที่ตั้งราคาไว้แล้ว ดูวิธีแก้ในสไลด์ถัดไป
ติ๊กเลือก 2 แผ่นจาก BDL-00004 — "2 selected" — จุดที่ Input ข้อมูล
⚠️ จุดห้ามลืม · เจอจริงระหว่างทำเดโม่นี้

2 อาการที่พนักงานอาจเจอจริง — ไม่ใช่ระบบพัง แก้ได้ทันที

Total ขึ้น 0.00 หลัง Confirm Selection ทั้งที่ตั้งราคาไว้แล้ว
Error "lot incompatible" ตอนกด Confirm SO
  • 1ราคา 0.00 หลัง Select Slabs — เกิดถ้าระบบดึงราคาจากแผ่นไม่สำเร็จ (แม้ Bundle ตั้ง Sales Price/Sq.Mt. ไว้แล้ว) — พนักงานแก้เองได้ที่ Unit Price บนบรรทัดขายโดยตรง (คำนวณจาก Sales Price/Sq.Mt. × พื้นที่รวมแผ่นที่เลือก)
  • 2"This lot ... is incompatible with this product" — เกิดถ้า Finish variant ของ Bundle ถูกตั้งหลังจากตัดแผ่นไปแล้ว วิธีแก้: เอาแผ่นออกจาก Select Slabs (คืนเป็น Available) → ลบแผ่นเดิมในบันเดิล → ตัดแผ่นใหม่หลังตั้ง Finish ให้ถูกต้องแล้วเท่านั้น

ขั้นตอนที่ 7 · ออกใบแจ้งหนี้ (รายได้)

Create Invoice → Regular Invoice → Confirm — AAA ติดป้ายมาให้เอง

  • 1จากหน้า SO ที่ Confirm แล้ว กด "Create Invoice" → เลือก "Regular invoice" → "Create Draft"
  • 2เช็คบรรทัดใบแจ้งหนี้ — คอลัมน์ Analytic จะมีป้าย "AAA" ติดมาให้เองแล้ว (ไม่ต้องพิมพ์เอง)
  • 3เช็คยอด/ราคาให้ตรงกับที่ตกลงลูกค้าอีกครั้ง → กด Confirm เพื่อ Post
Goal
รายได้ +13,920.00 บาท เข้าบัญชี AAA อัตโนมัติ — ไม่ต้องไปแปะ Analytic Account เองที่หน้า Invoice เลย
ข้อควรระวัง
ถ้าเป็นการออกบิลครั้งแรกที่อ้างอิงบัญชีธนาคารบริษัท อาจเจอเตือน "bank account not trusted" — ตั้ง Trusted ครั้งเดียวจบที่ Accounting → Bank Accounts
Draft Invoice — คอลัมน์ Analytic แปะป้าย "AAA" ให้อัตโนมัติ
ขั้นตอนที่ 8 · บันทึกต้นทุนจริง (ปิดวงจร)

สร้าง Vendor Bill จาก PO — ต้นทุนซื้อเข้า AAA ด้วยเช่นกัน

  • 1ไปที่ Invoicing → Vendors → Bills → New
  • 2เลือก Vendor → ช่อง Auto-Complete → เลือก PO ที่ต้องการ (P00062) — ระบบดึงบรรทัด+ราคา+ป้าย AAA มาให้ทั้งหมด
  • 3กรอก Bill Date (required) → Save → Confirm เพื่อ Post
Goal
ต้นทุนซื้อ -40,000.00 บาท เข้าบัญชี AAA — ตอนนี้เห็นครบทั้งขาซื้อและขาขายในที่เดียว
ข้อควรระวัง
ถ้าลืมสร้าง/Post Vendor Bill ขั้นนี้ Balance ของ Analytic Account จะโชว์แต่รายได้ ทำให้เข้าใจผิดว่ากำไรเกินจริงทั้งที่ยังไม่ได้บันทึกต้นทุน
BILL/2026/08/0002 Posted — 40,000.00 บาท ติดป้าย AAA
ผลลัพธ์ · Invoicing → Configuration → Analytic Accounts

เปิดดู Balance ของ AAA — เห็นภาพโปรเจกต์นี้ทันที ไม่ต้องกระทบยอดเอง

สรุปด่วน · ก่อนขึ้นพรีเซนต์จริง

4 จุดห้ามลืม ระหว่างพรีเซนต์ flow นี้

  • 1เช็ค Company ก่อนสร้าง Analytic Account เสมอ — ผูกตาม Company ที่ Active อยู่ตอนนั้นอัตโนมัติ สร้างผิดจะมีปัญหาข้ามบริษัททีหลัง
  • 2ตั้ง Sales Price/Sq.Mt. + Finish variant บน Bundle ให้ครบ "ก่อน" ตัดแผ่น — แก้ทีหลังทำให้แผ่นเดิมหาไม่เจอตอนขาย ต้องลบตัดใหม่
  • 3เช็คราคาบรรทัดขายทุกครั้งหลัง Select Slabs — อาจขึ้น 0.00 ได้แม้ตั้งราคาไว้แล้ว แก้มือได้ทันทีก่อน Confirm SO
  • 4อย่าลืมสร้าง + Post Vendor Bill จาก PO — ไม่งั้นต้นทุนจะไม่เข้า Analytic Account เลย ทำให้ดู Balance แล้วเข้าใจผิดว่ากำไรเกินจริง
สรุปภาพรวม

PO → Bundle → ตัดแผ่น → ขาย → Invoice — ตามรอยด้วย AAA ตัวเดียว

Purchase Order→ Bundle + AAA→ ตัดแผ่นมือ→ ขาย + Invoice→ Vendor Bill→ ดู Balance
สิ่งที่ลูกค้าเห็นวันนี้
Analytic Account เดียวตามรอยได้ทั้งซื้อ ผลิต และขาย — ไม่ต้องเปิดหลายรายงานมากระทบยอดเอง เห็นกำไร/ขาดทุนของหินแต่ละก้อนแบบ real-time ทันทีที่บันทึกครบทุกเอกสาร
