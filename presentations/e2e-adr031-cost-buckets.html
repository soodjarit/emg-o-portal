ขั้นตอนที่ 1 · เปิด Rate Library

เพิ่มไอคอนเปิดฟอร์มท้ายทุกแถว — จุดเข้าใหม่สู่ Cost Components

  • 1BOQ Estimation → Rate Library — list เดิมยังหน้าตาเหมือนเดิมทุกอย่าง (Material Cost, Labour Cost, Total Rate ยังอยู่ครบ)
  • 2List นี้เป็นแบบ editable — คลิกแถวจะเข้า inline-edit ไม่เปิดฟอร์มแบบปกติ
  • 3เพิ่มไอคอนลูกศรออก (⤢) ท้ายทุกแถว — กดแล้วเปิดฟอร์มเต็มของ Rate นั้นได้ทันที ไม่ต้องพึ่ง URL
Goal
ผู้ใช้ไม่ต้องรู้จัก URL/id ภายใน — มีปุ่มถาวรให้กดในหน้าจอปกติ
ข้อควรระวัง

Rate Library — คอลัมน์ไอคอนเปิดฟอร์มใหม่ท้ายทุกแถว
ขั้นตอนที่ 2 · ฟอร์มใหม่ที่ไม่เคยมีมาก่อน

"Cost Components" — ตารางย่อยแทนที่ 2 ช่องตายตัว

  • 1กดไอคอนที่แถว ST7-TEST (Rate ทดสอบ ปลอดภัยจะแก้ตรงๆ) → เปิดฟอร์มใหม่
  • 2เห็นตาราง Cost Components แสดง 2 แถวเดิม: Labour 650 / Material 3,350 — ตรงกับตัวเลขเดิมเป๊ะ
  • 3Total Rate / Unit = 4,000.00 ท้ายฟอร์ม — เหมือนที่เห็นในหน้า list ทุกประการ
Goal
Migration 13 Rate จริงเข้าโครงสร้างใหม่ ตัวเลขตรง 100% ไม่มีข้อมูลหาย
ST7-TEST — ตาราง Cost Components 2 แถว (Labour/Material)
⭐ จุดสำคัญของ ADR-031

เพิ่มหมวดต้นทุนที่ 3 ได้จากหน้าจอ — ไม่ต้องแก้โค้ด

กด "Add a line" → เลือก "Overhead" → ใส่ 500 → Total เปลี่ยนเป็น 4,500.00 ทันที
  • 1กด "Add a line" ในตาราง Cost Components → เลือกประเภท Overhead (มีให้เลือก 5 แบบ: Material / Labour / Overhead / Freight / Other) → ใส่ Note และจำนวนเงิน
  • 2"Total Rate / Unit" คำนวณใหม่ให้ทันที (3,350 + 650 + 500 = 4,500) — ไม่ต้องกด Save ก่อนถึงจะเห็นผลลัพธ์
  • 3"Material Cost"/"Labour Cost" เดิมไม่ถูกรบกวน — bucket ใหม่ไม่ไปปนกับตัวเลขเก่า ระบบแยกผลรวมตามประเภทให้ถูกต้องเสมอ
ขั้นตอนที่ 4 · ลบออก กลับสู่สภาพเดิม

กด ถังขยะ ลบ Overhead ออก → Total กลับ 4,000 ทันที ไม่มีร่องรอย

  • 1กดไอคอนถังขยะที่แถว Overhead → Save
  • 2ตาราง Cost Components กลับเหลือ 2 แถวเดิม (Labour 650 / Material 3,350)
  • 3Total Rate / Unit กลับเป็น 4,000.00 ตรงกับค่าตั้งต้นก่อนทดสอบทุกตัวเลข
Goal
ทดสอบเพิ่ม/ลบ bucket ได้อย่างมั่นใจ — ไม่ทิ้งข้อมูลเสียหายไว้ในระบบ ตรวจสอบซ้ำผ่านฐานข้อมูลจริงแล้วว่าสะอาด 100%
ข้อควรระวัง
Rate จริงที่ใช้งานลูกค้าอยู่ (ไม่ใช่ตัวที่มีคำว่า TEST) ควรทดสอบเพิ่ม/ลบ bucket ด้วยความระมัดระวังเช่นเดียวกับแก้ราคาปกติ เพราะมีผลต่อ BOQ Document จริง
ST7-TEST — กลับสู่สภาพเดิม Total 4,000.00
ยังไม่ทำ · รอคำตอบทีมบัญชี/ประเมินราคา

วันนี้แก้แค่ "โครงสร้างข้อมูล" — ยังไม่แตะหน้าใบเสนอราคาจริง

  • 1Layout ใบเสนอราคาจริง (twin Material/Labor) — จะแบ่งยอดย่อยต่อ bucket ยังไง, ตำแหน่ง WHT บนเอกสาร ยังไม่ได้ออกแบบ
  • 2ตัวคูณ % (Overhead 10% / VAT 7%) — ยังไม่รู้ว่าคิดแยกตาม bucket หรือคิดรวมฝั่ง Material/Labour เหมือนเดิม รอทีมประเมินราคายืนยัน
  • 3รายชื่อ bucket ที่ควรมีจริง — ตอนนี้มี 5 แบบตั้งต้น (Material/Labour/Overhead/Freight/Other) แต่ของจริงอาจมีมากกว่านี้ (ค่าธรรมเนียมยื่นแบบ, ค่าเช่าเครื่องมือ ฯลฯ) — รอ list จริงจากทีมประเมินราคา
สิ่งที่ทำได้แล้ววันนี้ ไม่ต้องรอใคร: โครงสร้างข้อมูลรองรับ bucket ไม่จำกัดแล้ว — พร้อมต่อยอดทันทีที่มีคำตอบจากทีมบัญชี/ประเมินราคา
สรุปภาพรวม

Rate Library เพิ่มหมวดต้นทุนได้ไม่จำกัด — ของเดิมยังใช้ได้ครบ 100%
