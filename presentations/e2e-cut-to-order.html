E2E — Cut to Order
ตัดแผ่นตามออเดอร์ (Mode 3, MRP) + รับชำระเงิน
เดินสด Odoo ครบวงจร ตั้งแต่เปิด Sale Order → สั่งตัดแผ่นผ่าน Manufacturing Order → ยืนยันขาย → ส่งของ → Invoice → รับชำระเงิน — พร้อมจุดห้ามลืมที่เจอจริงระหว่างเดิน flow 2 จุด
EMG-O · ADR-018 Mode 3 · ข้อมูลจริงจาก live run บน production 2026-08-03
ภาพรวม · สิ่งที่จะโชว์ลูกค้าวันนี้

ตัดแผ่นได้โดยไม่ต้องมีสต็อกล่วงหน้า — ระบบสั่งผลิตให้ตามออเดอร์จริง

i
Cut to Order คืออะไร ต่างจาก Select Slabs ยังไง
Select Slabs = เลือกจากแผ่นที่ตัดสำรองไว้แล้วในสต็อก แต่ถ้าไม่มีขนาดที่ลูกค้าต้องการพอดี ระบบมี "Cut to Order" — สั่งตัดแผ่นใหม่ตามขนาดที่ลูกค้าสั่งจริง ผ่าน Manufacturing Order (MRP) โดยไม่ต้องมี Sale Order แยกขั้นตอนเอง คลิกเดียวจากบรรทัดขายเลย เหมาะกับหินที่ลูกค้าสั่ง custom size บ่อย
1. เปิด SO + เลือกสินค้า→ 2. Cut to Order→ 3. MO ตัดแผ่น→ 4. Confirm SO→ 5. ส่งของ→ 6. Invoice→ 7. รับชำระเงิน
เดโม่นี้เจอจุดห้ามลืมจริง 2 จุดระหว่างเดิน flow (Bundle ไม่ auto-select ใน wizard, และต้องกรอก Scanned Serial เองตอนส่งของ) — เก็บไว้สอนเป็นจุดห้ามลืมในสไลด์เฉพาะ เพราะพนักงานจริงมีโอกาสเจอเหมือนกัน
ขั้นตอนที่ 1 · เปิดใบขาย

เปิด Sale Order → เลือกสินค้าหิน → ปุ่ม "Cut to Order" โผล่ขึ้นมาเอง

  • 1Sales → New → เลือกลูกค้า
  • 2"Add a product" → เลือกสินค้าแผ่นหิน (เช่น "Emperador Grey Light Marble Slab") → Save
  • 3ระบบโชว์ 2 ปุ่มบนบรรทัดขายอัตโนมัติ: "Select Slabs" (เลือกจากสต็อก) กับ "Cut to Order" (สั่งตัดใหม่)
  • 4เดโม่นี้เลือก "Cut to Order" — สมมติว่าไม่มีขนาดที่ลูกค้าต้องการในสต็อกพอดี
Goal
ระบบรู้เองว่าสินค้านี้เป็นหินแบบ Block-tracked ที่ตัดตามสั่งได้ ไม่ต้องตั้งค่าอะไรเพิ่ม
ข้อควรระวัง
ต้อง Save บรรทัดขายก่อน ปุ่ม "Cut to Order" ถึงจะกดได้จริง — กดตอนยังไม่ Save จะเจอ "Please save your changes first"
S108357 — บรรทัดขายพร้อม 2 ปุ่ม "Select Slabs" / "Cut to Order"
⚠️ จุดห้ามลืม #1 · เจอจริงระหว่างทำเดโม่นี้

Cut Order Wizard — "Cut From Block" ไม่เลือกให้อัตโนมัติ ต้องเลือกเอง

เปิด wizard — Material เติมให้อัตโนมัติ แต่ "Cut From Block" ว่างเปล่า
ถ้ากด Create Cut Order โดยไม่เลือก Block ก่อน → "Missing required fields"
  • 1"Material" auto-fill ให้จาก Product ที่เลือกบนบรรทัดขาย — ถูกต้องเสมอ ไม่ต้องแก้
  • 2"Cut From Block" ต้องเลือกเองทุกครั้ง แม้จะมี Bundle ของวัสดุนั้นอยู่ใบเดียวในระบบก็ตาม — ระบบกรอง dropdown ให้เฉพาะ Bundle ที่ตรง Material แล้ว แต่ไม่ได้เลือกให้อัตโนมัติ พนักงานต้องคลิกเลือกเอง 1 ครั้งเสมอ (จุดนี้อยู่ใน backlog ให้ทีมพิจารณาแก้ต่อ)
ขั้นตอนที่ 2 · กรอก wizard + สร้างใบสั่งตัด

เลือก Block → กรอกขนาดที่ต้องการ → ระบบสร้าง Manufacturing Order ให้ทันที

  • 1เลือก Cut From Block = Bundle ที่มีสต็อกพอ (ตัวอย่าง BDL-00008)
  • 2กรอก Target L (M) / Target H (M) ตามขนาดที่ลูกค้าสั่งจริง (ตัวอย่าง 1.20 × 1.80 ม.)
  • 3กด "Create Cut Order" — ระบบสร้าง Manufacturing Order (MO) ให้อัตโนมัติ พร้อม Confirm ทันที ไม่ต้องกดยืนยันซ้ำ
  • 4MO แสดง Component ที่จะใช้ (ก้อนหินดิบ) พร้อมปริมาณ CBM ที่คำนวณจากขนาด × ความหนาให้อัตโนมัติ
Goal
ตัวอย่างจริง: 1.20 × 1.80 × ความหนา 0.02 ม. = 0.04 m³ ตรงกับที่ MO คำนวณเป๊ะ
ข้อควรระวัง
ถ้า Block ที่เลือกมี CBM เหลือไม่พอ ระบบจะ error ทันทีตอนกด Create — เช็ค Remaining CBM ของ Bundle ก่อนเสมอถ้าสั่งตัดชิ้นใหญ่
MO EGWH/STCUT/00025 — Confirmed, Component 0.04/0.04 m³ พร้อมตัด
ขั้นตอนที่ 3 · จบการตัดจริง

กด "Complete Cut" — สร้างแผ่นใหม่ + เลข Lot + Hold เข้าใบขายให้เองในคลิกเดียว

  • 1บนหน้า MO กดปุ่ม "Complete Cut" (แทนที่ปุ่ม "Mark as Done" มาตรฐานของ MRP)
  • 2ระบบสร้าง Lot/Serial Number ใหม่ ให้แผ่นที่เพิ่งตัด ตั้งชื่อตาม Bundle อัตโนมัติ (เช่น BDL-00008-7)
  • 3MO เปลี่ยนสถานะเป็น Done — หัก CBM จากก้อนหินจริง
  • 4แผ่นใหม่ถูก Hold เข้าบรรทัดขายเดิมให้อัตโนมัติ — ไม่ต้องย้อนไปกด Select Slabs อีกรอบ
Goal
จากคลิก "Cut to Order" ครั้งเดียว จนได้แผ่นจริงพร้อมขาย ผูกกับใบขายเดิมครบในคลิกเดียวจบ ไม่มีขั้นตอนแมนวลเพิ่ม
ข้อควรระวัง
ปุ่มนี้โผล่เฉพาะ MO ที่มาจาก Cut to Order เท่านั้น (มี Stone Bundle ผูกอยู่) — MO ปกติอื่นๆ ยังใช้ "Mark as Done" แบบเดิม
MO Done — Lot/Serial "BDL-00008-7" สร้างสำเร็จ

ตอนส่งของ Validate ตรงๆ ไม่ผ่าน — ต้องกรอก "Scanned Serial" ก่อนเสมอ

เปิด "Details" บนบรรทัด Delivery — คอลัมน์ "Scanned Serial" ว่างเปล่า
พิมพ์เลข Lot เดียวกับที่โชว์ใน "Pick From" ลงช่องนี้ (ไม่มีเครื่องสแกนจริงก็พิมพ์ได้)
  • 1สินค้าหินทุกแผ่น track แบบ Serial Number — Odoo บังคับ "ยืนยัน" เลข Lot ก่อน Validate เสมอ ไม่ใช่แค่จองสต็อกไว้เฉยๆ พอ
  • 2วิธีแก้: บนหน้า Delivery กดลิงก์ "Details" ตรงบรรทัดสินค้า → คลิกช่อง "Scanned Serial" → พิมพ์เลข Lot ตัวเดียวกับที่โชว์ใน "Pick From" (เช่น BDL-00008-7) → Enter → Save → แล้วค่อยกด Validate อีกครั้ง — ถ้าลืมขั้นนี้จะเจอ Error "Invalid Operation — Scan verification failed"
ขั้นตอนที่ 5 · ส่งของสำเร็จ

ยืนยัน Serial แล้ว Validate ผ่าน — Delivery Order เข้าสถานะ Done

  • 1หลังกรอก Scanned Serial + Save แล้ว กลับมากด "Validate" อีกครั้งที่หน้า Delivery
  • 2สถานะเปลี่ยนจาก Ready → Done ทันที ไม่มี error
  • 3Stock ของแผ่นนี้ย้ายออกจาก "Stone Inventory/Stone Hold" ไปยังลูกค้าจริง
Goal
ปิดวงจรสต็อกฝั่งขาย — แผ่นที่ตัดใหม่ ตั้งแต่คลิกแรกจนถึงส่งของจริง ใช้เวลาไม่กี่นาที ไม่มีขั้นตอนตกหล่น
ข้อควรระวัง
ถ้ามีหลายบรรทัดสินค้าในใบเดียว ต้องกรอก Scanned Serial ให้ครบทุกบรรทัดก่อน Validate ถึงจะผ่าน

สรุปด่วน · ก่อนขึ้นพรีเซนต์จริง

4 จุดห้ามลืม ระหว่างพรีเซนต์ flow นี้

  • 1ต้อง Save บรรทัดขายก่อน ปุ่ม "Cut to Order" ถึงจะกดได้ — กดตอนยังไม่ Save จะเจอ error "Please save your changes first"
  • 2"Cut From Block" ใน wizard ไม่เลือกให้อัตโนมัติ — ต้องคลิกเลือก Bundle เองเสมอ แม้จะมีตัวเลือกเดียวก็ตาม ไม่งั้นเจอ "Missing required fields"
  • 3ตอนส่งของ ต้องกรอก "Scanned Serial" ก่อน Validate เสมอ — เปิด "Details" บนบรรทัดสินค้า พิมพ์เลข Lot เดียวกับที่โชว์ใน "Pick From" (ไม่ต้องมีเครื่องสแกนจริง) แล้วค่อย Validate
  • 4เช็ค Remaining CBM ของ Block ก่อนสั่งตัดชิ้นใหญ่ — ถ้าไม่พอ ระบบ error ทันทีตอนกด "Create Cut Order" ป้องกันตัดเกินสต็อกจริงอยู่แล้ว ไม่ต้องกังวลเรื่องข้อมูลผิดพลาด
