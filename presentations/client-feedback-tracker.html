1. Slab thickness เป็น Attribute / Block ไม่มี Thickness-Finish
เสร็จแล้ว
"หินบล็อกธรรมชาติยังไม่ผ่านการแปรรูป จึงไม่ควรมีฟิลด์ความหนา (Thickness) หรือ Finish...ควรกำหนดมิติด้วยขนาด กว้าง×ยาว×สูง (CBM) และคิดน้ำหนักเป็น 'ตัน' [25 ก.ย. 69]" + "สำหรับแผ่นสแลป เสนอให้ใช้ความหนามาตรฐาน (2, 2.5, 3, 5 cm) เป็น Attribute โดยไม่ต้องแยกเป็น Product Code ใหม่ เพื่อป้องกันรหัสสินค้าแตกกระจายเกิน 500+ รหัส [25 ก.ย. 69]"
สิ่งที่ทำ: Built จริง — Block ถอด Thickness/Finish ออกหมด ยึด กว้าง×ยาว×สูง เป็นข้อมูลหลัก, Thickness ของ Slab เป็น Attribute จริง ผูกกับแต่ละแผ่น (ไม่ใช่ Block/Bundle) — verified ทั้ง odoo shell และ Playwright
📍 จุดตรวจสอบ: Sales > เปิด SO บรรทัด Slab ใดๆ > ดู Attribute "ความหนา" ที่ตัวแปรสินค้า หรือ Settings > Attributes > "Thickness" (6 ค่า) — DB eg-tst/mbx-ee-dev
