สิ่งที่ธุรกิจต้องการจริงๆ (ไม่เกี่ยวกับชื่อเรียก)
(1) เก็บเกรด/คุณภาพต่อก้อน (2) เก็บต้นทุนจริงต่อก้อน แยกจากก้อนอื่น (3) เชื่อมกับตู้ Container เพื่อกระจายค่าขนส่งได้ถูกต้อง — ทั้ง 3 ข้อนี้จำเป็นไม่ว่าจะเรียกกลไกที่เก็บมันว่า "Bundle" หรือชื่ออื่นก็ตาม

Core Model Version + Shared Instance

ความเสี่ยงตอน Odoo อัปเกรดเวอร์ชัน
stock.lot เป็นโมเดลที่ Odoo core team แก้ไขข้ามเวอร์ชันอยู่เรื่อยๆ (เคยเปลี่ยนชื่อทั้งโมเดลมาแล้วในอดีตจาก stock.production.lot) — field ที่แปะเพิ่มเข้าไปเสี่ยงชนกับการอัปเดตเวอร์ชันในอนาคต จริงไม่ว่าจะสร้างวันนี้หรือปีที่แล้ว
ความเสี่ยง Shared Instance (สถานะปัจจุบัน)
ตราบใดที่ยังไม่ได้ย้ายไป instance เฉพาะ — field เฉพาะของหินที่แปะบน stock.lot จะไปโผล่ในฟอร์ม Lot ของ MBX Café/VOLTA AV/VIVO Sport/Memberbox ด้วยจริง เคยเกิด incident แบบนี้มาแล้วกับโมเดลกลางอื่น (project.task, route-access)
