ขั้นตอนที่ 1 · สร้าง/อัปเดต Rate Library

รายละเอียดขั้นตอน

  • 1เปิด BOQ Estimation → Rate Library → กด New
  • 2กรอก Item Code, Description, Unit, Material Cost, Labour Cost — Total Rate คำนวณให้อัตโนมัติ
  • 3ตั้งชื่อ Item Code ให้จำง่าย ทีมขายจะค้นหาด้วยชื่อนี้ตอนสร้าง BOQ Document
  • 4Save — Rate นี้พร้อมให้ทีมขายค้นหาและเลือกใช้ได้ทันที
ต้นทุนเปลี่ยน? แก้ที่ Rate Library ตัวเดียวจบ ทุก BOQ Document ใหม่ที่เลือก Rate นี้จะได้ราคาที่อัปเดตทันที — เอกสารเก่าที่สร้างไปแล้วไม่เปลี่ยนตามย้อนหลัง
อัปเดต (ADR-031): ตอนนี้เพิ่มหมวดต้นทุนได้เองนอกเหนือจาก Material/Labour (เช่น Overhead, Freight, Other) ผ่านเมนู "Cost Component Types" แต่ละหมวดตั้ง Adder % ของตัวเองแยกกันได้ — Rate เดิมทุกตัวยังทำงานเหมือนเดิม ไม่กระทบ ดูรายละเอียดที่ เอกสาร BOQ Estimation อัปเดต →

รายละเอียดขั้นตอน

  • 1เปิด Rate Library → คลิกช่อง "Product" ของ Rate item ที่เพิ่งสร้าง
  • 2เลือกสินค้าจริงในคลัง — สำหรับหิน เลือก Finish variant ของ Material นั้นให้ตรง (เช่น honed/polished)
  • 3Save
  • 4ทำซ้ำทุก Rate ใหม่ที่สร้าง — Rate เก่าที่เคยผูกไว้แล้วไม่ต้องทำซ้ำ
ผลลัพธ์: BOQ Document ใหม่ที่ใช้ Rate นี้ → ทีมขายกด "สร้างใบเสนอราคา" → บรรทัดกลายเป็นสินค้าจริงทันที พร้อมปุ่ม Select Slabs ให้ทีม Operation กดทำงานต่อ

3
สถานการณ์จริง
ก่อนบอกทีมขายว่า "ใช้ Rate ตัวใหม่ได้แล้ว" ควรทดสอบเองก่อน 1 รอบ — ถ้าลืมผูก Product หรือกรอกหน่วยผิด จะเจอตอนทดสอบเอง ไม่ใช่ตอน sale กำลังคุยกับลูกค้าจริง
เช็คลิสต์ก่อนปล่อยให้ทีมขายใช้
  • สร้าง Rate ใหม่ครบ (Item Code/Unit/Cost/Total Rate ถูกต้อง)
  • ผูก Product กับ Rate ทุกตัวแล้ว
  • สร้าง BOQ Document ทดสอบ → กดสร้างใบเสนอราคา → เห็นบรรทัดเป็นสินค้าจริง มีปุ่ม Select Slabs
  • ลบ/archive เอกสารทดสอบทิ้ง ไม่ปนกับข้อมูลจริง
