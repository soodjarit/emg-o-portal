สายการผลิตเดียว — ขายได้ทั้ง 3 จุดบนสายนี้ พร้อมแปะสวิตช์ Project/BOQ ได้ทุกจุด
EMG-O · แนวคิด EG-321
3 จุดขาย

ขายได้ 3 จุด บนสายการผลิตเดียวกัน

1
Block
ขายก้อนหินดิบทั้งก้อน ยังไม่ตัดอะไรเลย
ตัวอย่าง: ลูกค้าซื้อก้อนหินอ่อน Carrara 1 ก้อน เอาไปตัดเองที่โรงงานตัวเอง
2
Slab
ขายแผ่นหินที่ตัดจาก Block แล้ว (มีอยู่แล้วในสต๊อก หรือสั่งตัดใหม่ — รายละเอียดวิธีจัดหาของเท่านั้น)
ตัวอย่าง: ลูกค้าต้องการหินแกรนิต 5 ตร.ม. ปูพื้น มีของอยู่แล้วก็ส่งเลย ไม่มีก็ตัดให้ก่อน
3
FG
ขายของสำเร็จรูปที่แปรรูปต่อจาก Slab แล้ว
ตัวอย่าง: เคาน์เตอร์ครัวสำเร็จรูป และงานแกะสลักพิเศษอย่าง เจดีย์บัว (สูตรผลิตซับซ้อนกว่า แต่ยังเป็น FG เหมือนกัน)

2 สวิตช์

แปะได้กับจุดขายไหนก็ได้ อิสระจากกัน

Project
ติดตามงานเป็นขั้นตอน (Task/Gantt) + เก็บเงินเป็นงวดตาม Milestone
ตัวอย่าง: งานสั่งทำเจดีย์บัว ผ่อนจ่าย 3 งวด อยากเห็นความคืบหน้าแต่ละขั้น
BOQ
เริ่มจากทำเอกสารประเมินราคาก่อน แล้วแปลงเป็นใบเสนอราคาให้อัตโนมัติ
ตัวอย่าง: งาน Countertop หลายรายการ ต้องให้ทีมประเมินราคาก่อนเสนอลูกค้า
ตัวอย่างลูกค้าจุดขายProjectBOQ
ซื้อ Block ไปตัดเอง จ่ายเงินสดBlock❌❌
สั่งเจดีย์บัว ผ่อนจ่าย 3 งวดFG✅อาจมีหรือไม่มี
Countertop ราคาปกติ จ่ายครบ แต่มีหลายรายการต้องประเมินราคาก่อนFG❌✅

เดิม vs ใหม่

เดิม — 5 Modes

1. Block Direct Sale
2. Ready-Made Slab
3. Block-to-Slab
4. Sold-as-Project
5. FG Production

→ ดูเหมือนเป็น 5 ทางเลือกที่แยกขาดจากกัน ทั้งที่บางอย่างซ้อนกันอยู่

ใหม่ — EG-321

3 จุดขาย (Block / Slab / FG) — บนสายการผลิตเดียวกัน

2 สวิตช์ (Project / BOQ) — แปะจุดไหนก็ได้ อิสระต่อกัน

→ เห็นภาพรวมชัดขึ้น ว่าอะไรคือ "ขายอะไร" กับ "ติดตามยังไง" แยกจากกันจริง
หมายเหตุ: ระบบเบื้องหลัง (wizard, กลไกการผลิต) ไม่ได้เปลี่ยนแปลง — เปลี่ยนแค่วิธีอธิบาย/ทำความเข้าใจ และหน้าจอ UX บางจุดเท่านั้น
