1 โครงสร้างข้อมูล 4 วิธีขาย ไม่ใช่ระบบแยกกันคนละชุด

?
ที่มา
หลังลูกค้า (Empire Stone) กลับมาต่องานกลางทาง ได้ reframe requirement ใหม่เป็น 4 โหมดการขาย ครอบคลุมสินค้า/วิธีขายที่ต่างกันของธุรกิจหิน — ทุกโหมดใช้ Material → Block → Bundle → Slab เดียวกันหมด
#ประเภทขายอะไรตัดสต็อกตอนไหนความละเอียดสต็อก
1หินก้อนนำเข้าก้อนหินทั้งก้อน (m³)ตอนขาย (ไม่ตัด)ทั้งก้อน ไม่แบ่งขาย
2แผ่นหินสำเร็จรูปแผ่นที่ตัดสำรองไว้แล้วตัดล่วงหน้า เก็บรอขายแพง=รายแผ่น(Serial) / ถูก=รวมล็อต(ตร.ม.)
3ตัดตามสั่ง (Cut-to-Order)แผ่นที่ยังไม่มีอยู่จริงตัดหลังยืนยัน SO (ผ่าน MRP)รายแผ่น (Serial)
4งานโครงการ (Sold-as-Project)ชุด BOQ (วัสดุ+ค่าแรงหลายรายการ)แล้วแต่รายการ (ผสมโหมด 1-3 ได้)ติดตามระดับโครงการผ่าน Analytic Account
หลักคิดสำคัญ: โหมด 1-3 ตอบคำถาม "ขายสต็อกยังไง" ส่วนโหมด 4 เป็นคนละมิติ — คือ "ขายเป็นชุดโครงการ" ซึ่งข้างในแต่ละบรรทัด BOQ ยังใช้กลไกโหมด 1-3 อยู่ดี เพียงแต่เพิ่ม Project+Gantt+Billing แบบงวดคลุมทั้งหมด
ประเภท 1
หินก้อนนำเข้า · Imported Stone Block

ขายทั้งก้อน ไม่ตัด หน่วยเป็น CBM (m³)

  • 1ใช้ตอนลูกค้าต้องการวัตถุดิบไปตัดเอง (โรงงานอื่น หรือ intercompany EG↔ES)
  • 2สินค้าคนละ SKU กับแผ่น (product_id_block) แต่เป็น Material เดียวกัน — ไม่ผ่าน wizard เลือกแผ่น ใช้ flow ขายมาตรฐานของ Odoo
  • 3SO line กด "Sell Whole Block" → Select Block Wizard → เลือก Bundle → ระบบตั้ง qty = remaining_cbm ทั้งหมดอัตโนมัติ (ขายทั้งก้อน แบ่งขายบางส่วนไม่ได้)
ตัวอย่างจริง: Bundle EMG-B-0003 (Emperador Grey Light Marble) เหลือ 2.65 m³ → กด Sell Whole Block → Quantity เปลี่ยนเป็น 2.65 อัตโนมัติ → ราคารวม 2.65 × 3,500 = ฿9,275
Workflow: ซื้อ → รับเข้าคลัง → ขายทั้งก้อน → ส่งของ → บัญชี
ประเภท 2
แผ่นหินสำเร็จรูป · Ready-Made Slab

ตัดสำรองไว้ล่วงหน้า — แยกวิธีคุมสต็อกตามราคาหิน

  • 1หินแพง (Serial ต่อแผ่น): ทุกแผ่น = 1 Lot แยกกัน ลูกค้าเลือกแผ่นจริงจากลาย/ขนาดผ่าน Select Slabs Wizard — มี scan ยืนยันตอนส่งของ
  • 2หินถูก (รวมเป็นล็อต): ไม่ผูก Serial รายแผ่น สต็อกอยู่ระดับ Bundle (remaining_sqmt) ขายบางส่วนได้ (Partial Quantity)
  • 3pricing_mode ตั้งที่ระดับ Material — ล็อกทันทีที่มี Bundle แรกเกิดขึ้น เปลี่ยนภายหลังไม่ได้
ตัวอย่างจริง 2 แบบ: หินแพง — EMG-B-0001 (5 แผ่น) ลูกค้าเลือกเฉพาะแผ่นที่ต้องการผ่าน Select Slabs · หินถูก — ขายบางส่วน 2.5 จาก 6.0 ตร.ม. ผ่าน Select Lot Stock โดยไม่ต้องซื้อยกล็อต
Workflow: ซื้อ → ตัด → ขาย (Serial หรือ Lot) → บัญชี
ประเภท 3
ตัดตามสั่ง · Cut-to-Order (MRP)

ยังไม่มีแผ่นจริง — ลูกค้าสั่ง Finish+ขนาดเอง แล้วค่อยตัด

  • 1โหมดเดียวที่ใช้ Odoo MRP จริง (Work Center "Stone Cutting") — ต่างจากประเภท 2 ที่ "ตัด" เป็น custom transformation ธรรมดา
  • 2ต้องตั้ง Finish attribute บน Product Template (Polished/Honed/Brushed/Sandblasted/Other) ก่อนถึงจะมีตัวเลือกให้ลูกค้าสั่งจริง
  • 3SO line เลือก Finish → ปุ่ม "Cut to Order" → Wizard สร้าง Manufacturing Order → Complete Cut → แผ่นใหม่พร้อม Serial Lot ตรง Finish ที่สั่งจริง
บทเรียนจากบั๊กจริง 3 ชั้น (แก้แล้ว 2026-07-19): ระบบเคยผูก "1 Bundle = 1 Finish เดียว" ทำให้ปุ่มหาย/wizard หาแผ่นไม่เจอ/ผลิตผิด Finish เมื่อ Bundle เดียวถูกสั่งตัดหลาย Finish จริง — แก้ให้เชื่อ SO line/Lot ของแต่ละแผ่นเป็นแหล่งความจริง ไม่ใช่ field เดียวบน Bundle
Workflow: ซื้อ → ตัดตามสั่ง (MRP) → ขาย → บัญชี
ประเภท 4
งานโครงการ · Sold-as-Project (BOQ)

ขายเป็นชุดงาน — เพิ่ม 3 อย่างที่โหมดอื่นไม่มี
