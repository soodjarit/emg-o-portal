โหมด 3: ตัดตามสั่ง
(Cut-to-Order)
เดินสดตั้งแต่มี Block พร้อมอยู่แล้วในสต็อก ยืนยัน SO ทั้งที่ยังไม่มีแผ่นจริง ให้ระบบขึ้นคิวงานอัตโนมัติที่หน้า "Factory Worklist" ให้ฝ่ายผลิตเลือกก้อน+ระบุขนาดตัดเอง ผ่าน Manufacturing Order จนถึงราคาคำนวณอัตโนมัติและออกใบแจ้งหนี้ — ไม่ต้องให้ฝ่ายขายเป็นคนตัดสินใจว่าจะตัดจากก้อนไหน (ขั้นตอนซื้อ+รับหินเข้าคลังดูที่เดค Ensure Supply แยกต่างหาก)

ระบบขายหินมี 5 โหมด — เดโมนี้พาไปดูโหมดที่ 3

#ประเภทขายอะไรตัดสต็อกตอนไหนความละเอียดสต็อก
1หินก้อนนำเข้าก้อนหินทั้งก้อน (m³)ตอนขาย (ไม่ตัด)ทั้งก้อน ไม่แบ่งขาย
2แผ่นหินสำเร็จรูปแผ่นที่ตัดสำรองไว้แล้วตัดล่วงหน้า เก็บรอขายแพง=รายแผ่น(Serial) / ถูก=รวมล็อต(ตร.ม.)
3ตัดตามสั่ง (Cut-to-Order)แผ่นที่ยังไม่มีอยู่จริงตัดหลังยืนยัน SO (ผ่าน MRP)รายแผ่น (Serial)
4งานโครงการ (Sold-as-Project)ชุด BOQ (วัสดุ+ค่าแรงหลายรายการ)แล้วแต่รายการติดตามระดับโครงการผ่าน Analytic Account
5FG Productionสินค้าสำเร็จรูปตัดจาก Slab อีกทีตัดหลังยืนยัน SO (ผ่าน MRP)รายชิ้น (Serial) + อาจมีเศษ/byproduct
โหมด 3 คือหินที่ยังไม่มีแผ่นอยู่จริงตอนขาย — ต่างจากโหมด 2 ตรงที่ไม่มีสต็อกแผ่นสำเร็จรอไว้ ต้องสั่งตัดใหม่ทุกครั้งผ่านใบสั่งผลิต (Manufacturing Order) โดยฝ่ายขายแค่ยืนยัน SO แล้วส่งต่อให้ฝ่ายผลิตเป็นคนตัดสินใจว่าจะตัดจากก้อนไหน ขนาดเท่าไหร่
เดคนี้เริ่มนับจากมี Block พร้อมอยู่แล้วในสต็อก — ขั้นตอนซื้อก้อนหิน+รับเข้าคลังเป็น flow เดียว ใช้ร่วมกันทุกโหมด ดูแยกที่เดค Ensure Supply — รับหินเข้าคลัง
แผนผังขั้นตอน

Flow โหมด 3 ทั้งหมด — 4 ฝ่าย 8 ขั้นตอน

เริ่มนับจากมี Block พร้อมอยู่แล้ว — จุดต่างจากโหมด 2 คือ SO ถูกยืนยันไปก่อนโดยยังไม่มีแผ่นจริง แล้วขั้นตอน "รับช่วงตัด" จะย้อนกลับไปที่ฝ่ายคลัง/ผลิตอีกครั้งผ่านหน้า Factory Worklist — กล่องที่กำลังอธิบายจะถูก ไฮไลท์สีแดง ทีละขั้นตอน
หมายเหตุ: แผนผังนี้ยังเป็นเวอร์ชันก่อนดีไซน์ใหม่ 2026-08-16 (ยังไม่มีกล่อง "ย้าย Block ไปสถานีตัด") — จำนวนขั้นตอนจริงตอนนี้คือ 8 ไม่ใช่ 6 กล่องตามภาพ ดูขั้นตอนที่ 5 (ย้าย Block) แยกในสไลด์ถัดไป
