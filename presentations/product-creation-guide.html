อีกชั้นที่ควรรู้จัก

ตู้คอนเทนเนอร์ → ก้อนหิน → ป้ายสต็อก คืออะไร

📦 Container
ตู้คอนเทนเนอร์ที่ขนส่งมาจริง 1 เที่ยว — เหมือนกล่องพัสดุใบใหญ่ มีวันที่คาดว่าจะถึง/ถึงจริง และค่าขนส่งจริง 1 บิล
🪨 Bundle
หินแต่ละก้อนที่อยู่ในตู้นั้น — เหมือนของแต่ละชิ้นในกล่อง นี่คือสิ่งที่พนักงานกรอกข้อมูลจริงตอนรับของ
🏷️ Lot
ป้ายที่ระบบสร้างให้อัตโนมัติตอนบันทึก Bundle เพื่อนับสต็อกเบื้องหลัง — พนักงานไม่ต้องสร้างหรือแตะเอง
ตัวอย่างจริง: Container EMG-CNT-001 มี 2 Bundle อยู่ข้างใน
สรุปสั้นๆ: พนักงานเห็นแค่ Container กับ Bundle เท่านั้นในการทำงานจริง — ส่วน Lot เป็นกลไกของ Odoo เองที่ทำงานอยู่เบื้องหลัง
ตอนที่ 2 — ลงมือสร้างจริง

5 เงื่อนไขที่ต้องตัดสินใจตอนสร้าง Product

  • 1พื้นฐาน — ทุกวัสดุต้องมี Material + Slab Product เสมอ
  • 2จะขายทั้งก้อนด้วยไหม? → เปิด Block Product
  • 3หินราคาถูก/จำนวนมากไหม? → ตั้ง Pricing Mode = Lot
  • 4ให้ลูกค้าเลือก Finish (ขัดเงา/ด้าน) เองไหม? → เพิ่ม Finish Attribute
  • 5เป็นงานโครงการที่มีค่าแรงด้วยไหม? → สร้างสินค้าประเภท Service
แต่ละข้อไม่ต้องเลือกอันเดียว — วัสดุตัวหนึ่งเปิดได้หลายเงื่อนไขพร้อมกัน (เช่น ขายทั้งก้อนได้ และมี Finish ให้เลือกด้วย)
เงื่อนไขที่ 1 · พื้นฐานทุกวัสดุ
สร้าง Material + Slab Product

Configuration → Materials → New

  • 1Configuration → Materials → New — ตั้งชื่อ, Category, Origin Country
  • 2Slab Product (บังคับกรอกเสมอ) — พิมพ์ชื่อสินค้าใหม่ → Create and edit... → ตั้ง Sales Price/Cost
  • 3เปิด Track Inventory → เลือก By Unique Serial Number → Save
ทำไมต้อง Serial: หินแต่ละแผ่นลาย/ขนาดไม่เหมือนกัน ระบบต้องรู้ว่าส่งแผ่นไหนจริงไปให้ลูกค้าคนไหน
หน้าจอจริง: Slab Product ตั้ง Track Inventory = By Unique Serial Number
เงื่อนไขที่ 2 · ทางเลือก
เปิดโหมด "ขายทั้งก้อน"

Block Product — field นี้แหละที่เปิดการขายก้อนทั้งก้อน

  • 1Block Product (ทางเลือก) → Create and edit... → ตั้ง Sales Price/Cost
  • 2เปิด Track Inventory → เปลี่ยนหน่วยเป็น m³ → Tracking เลือก By Lots → Save
  • 3กลับมาหน้า Material → กด Save อีกครั้ง — เสร็จแล้ว ทั้ง 2 สินค้าพร้อมใช้งาน
⚠ จุดที่มักพลาด: ต้องเปิดฟีเจอร์ "Units of Measure" ก่อน (Inventory → Configuration → Settings) ไม่งั้นช่องหน่วย m³ จะไม่โผล่ให้เลือก
หน้าจอจริง: Block Product หน่วย m³, Tracking = By Lots
เงื่อนไขที่ 3 · ทางเลือก
หินราคาถูก / จำนวนมาก

Pricing Mode = Lot — ไม่ต้องแยก Serial รายแผ่น

  • 1Materials → New → กรอก Name/Category ตามปกติ
  • 2Pricing Mode → เลือก "Lot (aggregate, cheap stone)" — จุดเดียวที่ต่างจากหินแพง
  • 3Slab Product → ตั้งราคา → เปิด Track Inventory → ปล่อย Tracking ค่า default ไว้ → Save
Pricing Mode = Lot (aggregate, cheap stone)
Tracking เปลี่ยนเป็น "By Lots" ให้อัตโนมัติ
เหมาะกับ: หินมาตรฐานที่แผ่นแทบไม่ต่างกัน ราคาถูก ไม่คุ้มจะ track รายแผ่น — เลือกได้ตั้งแต่ตอนสร้าง ล็อกทันทีที่มี Bundle แรกเกิดขึ้น
เงื่อนไขที่ 4 · ทางเลือก
ให้ลูกค้าเลือก Finish เอง

ตั้ง Finish Attribute บนตัว Product Template

  • 1สร้าง Material + Slab Product ตามปกติ (เหมือนเงื่อนไข 1)
  • 2เปิดสินค้าแบบฟอร์มเต็ม ผ่าน Sales → Products → Products
  • 3แท็บ Attributes & Variants → Add a line → เลือก "Finish" → เลือกค่าที่รองรับ (เช่น Polished, Honed) → Save
⚠ ต้องเปิดก่อน: ฟีเจอร์ "Variants" (Sales → Configuration → Settings) ไม่งั้นแท็บนี้จะไม่โผล่เลย
หน้าจอจริง: Rosa Portogallo ตั้ง Finish = Polished + Honed
เงื่อนไขที่ 5 · ทางเลือก
งานโครงการที่มีค่าแรง

สินค้าประเภท Service — สำหรับค่าแรง/บริการ

  • 1Sales → Products → Products → New (ไม่ผ่านฟอร์ม Material เพราะไม่ใช่หินที่ต้องคุมสต็อก)
  • 2ตั้งชื่อ เช่น "ค่าแรงติดตั้งหน้างาน"
  • 3Product Type → เลือก "Service" — ไม่มี Track Inventory ให้ตั้ง เพราะไม่มีสต็อกจริง → ตั้งราคา → Save
เอาสินค้า Service นี้ไปใส่รวมกับบรรทัดวัสดุใน SO เดียวกัน แล้วติ๊ก "ขายแบบโครงการ" ตอนยืนยัน — ระบบจะรวมต้นทุน+รายได้ให้ดูกำไรที่โครงการเดียว
หน้าจอจริง: สินค้า Service ตั้ง Product Type = Service
สรุป · ก่อนเริ่มสร้าง

Checklist 5 คำถามก่อนสร้าง Product

  • 1วัสดุนี้เป็นชนิดหินใหม่ที่ยังไม่มีในระบบใช่ไหม? → เริ่มที่ Configuration → Materials → New เสมอ
  • 2ลูกค้าจะซื้อทั้งก้อนไปตัดเองไหม? → เปิด Block Product ตั้งหน่วย m³
  • 3เป็นหินราคาถูก ไม่คุ้มแยกรายแผ่นไหม? → Pricing Mode = Lot ตั้งแต่ตอนสร้าง (แก้ทีหลังไม่ได้)
  • 4อยากให้ลูกค้าเลือกผิว (Finish) เองไหม? → เพิ่ม Finish Attribute ที่ Product Template
  • 5งานนี้มีค่าแรง/บริการรวมด้วยไหม? → สร้างสินค้า Service แยกต่างหาก
ขั้นต่อไป

สร้าง Product เสร็จแล้ว ยังขายไม่ได้ทันที — ต้องมี Bundle ก่อน

สร้าง Material + Product→ ซื้อ (PO) → รับเข้า Container/Bundle→ มีสต็อกจริง → ขายได้
เรื่องต้องรู้ก่อนตัดสินใจ
Bundle ต้องมาจากไหนผ่านการรับสินค้าจริงผ่าน PO เท่านั้น — สร้าง Bundle ลอยๆ จะไม่ผูก Product อัตโนมัติ
