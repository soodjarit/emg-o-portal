(Sold-as-Project)
เดินสดตั้งแต่ทำ BOQ ประเมินราคาจากคลัง Rate Library หลายรายการ สร้างใบเสนอราคา ยืนยันเป็นโครงการให้ระบบสร้าง Project + Task + Milestone อัตโนมัติ จนถึงออกใบแจ้งหนี้ตามงวด 30/40/30 ที่ระบบหักยอดที่จ่ายไปแล้วให้เองอัตโนมัติ

ระบบขายหินมี 5 โหมด — เดโมนี้พาไปดูโหมดที่ 4

#ประเภทขายอะไรตัดสต็อกตอนไหนความละเอียดสต็อก
1หินก้อนนำเข้าก้อนหินทั้งก้อน (m³)ตอนขาย (ไม่ตัด)ทั้งก้อน ไม่แบ่งขาย
2แผ่นหินสำเร็จรูปแผ่นที่ตัดสำรองไว้แล้วตัดล่วงหน้า เก็บรอขายแพง=รายแผ่น(Serial) / ถูก=รวมล็อต(ตร.ม.)
3ตัดตามสั่ง (Cut-to-Order)แผ่นที่ยังไม่มีอยู่จริงตัดหลังยืนยัน SO (ผ่าน MRP)รายแผ่น (Serial)
4งานโครงการ (Sold-as-Project)ชุด BOQ (วัสดุ+ค่าแรงหลายรายการ)แล้วแต่รายการติดตามระดับโครงการผ่าน Analytic Account
5FG Productionสินค้าสำเร็จรูปตัดจาก Slab อีกทีตัดหลังยืนยัน SO (ผ่าน MRP)รายชิ้น (Serial) + อาจมีเศษ/byproduct
โหมด 4 คืองานที่มีหลายรายการรวมกันเป็นโครงการเดียว — ต่างจากโหมด 1-3 ตรงที่ไม่ได้ขายสินค้าชิ้นเดียว แต่รวมวัสดุ+ค่าแรงหลายบรรทัดจาก BOQ เข้าด้วยกัน แล้วให้ระบบสร้าง Project พร้อมงวดชำระเงินอัตโนมัติ เพื่อติดตามความคืบหน้าและวางบิลเป็นงวดได้

flow นี้เป็นเส้นตรง ไม่มีจุดแยกทาง — ฝ่ายขายทำ BOQ+ใบเสนอราคาจนจบ แล้วส่งต่อให้ฝ่ายโครงการดูแลงานจริง จบด้วยฝ่ายบัญชีวางบิลเป็นงวด — กล่องที่กำลังอธิบายจะถูก ไฮไลท์สีแดง ทีละขั้นตอน
ขั้นตอนที่ 1 / 7 · ฝ่ายขาย/ประเมินราคา

สร้าง BOQ Document — ระบุลูกค้า + Analytic Account

คลิกรูปเพื่อขยาย
ลูกค้า Demo Customer - Grand Interior, ผูก Analytic Account เฉพาะโครงการนี้, ตั้ง Preliminaries 5% + Performance Security 5%
Analytic Account คือกุญแจสำคัญของโหมดนี้ — ทุกต้นทุน/รายได้ของโครงการจะถูกแท็กเข้าบัญชีเดียวกัน ทำให้ดูกำไรจริงของแต่ละโครงการแยกจากกันได้ในภายหลัง
ขั้นตอนที่ 2 / 7 · ฝ่ายขาย/ประเมินราคา

เพิ่มรายการจาก Rate Library — คิดต้นทุน+Overhead ให้อัตโนมัติ

คลิกรูปเพื่อขยาย
BOQ0030 — 3 รายการจากคลัง Rate (Wall Finishes 45 ตร.ม., Base Molding 20 ตร.ม., Scaffolding 1 งาน) รวม 1,019,700 บาท (รวม Preliminaries/Overhead/Performance Security)
แต่ละรายการดึงราคาและต้นทุนจริงจาก Rate Library มาให้เอง — ไม่ต้องคีย์ราคาต้นทุนแยกทีละองค์ประกอบ (วัสดุ/ค่าแรง/Overhead) ระบบคำนวณสรุปให้ตั้งแต่ระดับ BOQ
ขั้นตอนที่ 3 / 7 · ฝ่ายขาย/ประเมินราคา

กด "สร้างใบเสนอราคา" — ได้ Sale Order ผูกกับ BOQ ทันที

คลิกรูปเพื่อขยาย
S108407 — สร้างจาก BOQ0030 อัตโนมัติ ยอดตรงกัน 1,019,700 บาท พร้อมบรรทัด Preliminaries/Overhead & Profit/Performance Security แยกให้เห็นชัดเจน
ใบเสนอราคาที่ได้ไม่ใช่แค่ยอดรวมก้อนเดียว — แตกเป็นบรรทัดตาม Schedule/Zone พร้อมสรุป Overhead แยกให้ลูกค้าเห็นที่มาของราคาชัดเจน
ขั้นตอนที่ 4 / 7 · ฝ่ายขาย/ประเมินราคา

ติ๊ก "Sold as Project" แล้วยืนยัน SO

คลิกรูปเพื่อขยาย
ยืนยันแล้ว — ช่อง "Sold as Project" ติ๊กไว้ ระบบขึ้น Project อัตโนมัติทันที (ปุ่ม "1 Projects / 6 Tasks" โผล่ที่มุมบนขวา)
"Sold as Project" เป็นตัวเลือกที่ฝ่ายขายกดเองก่อนยืนยัน — ใบขายทั่วไปที่ไม่ติ๊กจะไม่สร้าง Project ให้ ใช้เฉพาะงานที่ต้องติดตามความคืบหน้าและวางบิลเป็นงวดจริง
ขั้นตอนที่ 5 / 7 · ฝ่ายโครงการ

ระบบสร้าง Project + Task ต่อบรรทัด + Milestone 30/40/30 ให้เองทันที

Task — 1 งานต่อ 1 บรรทัด BOQ
Milestone 3 งวด — สร้างอัตโนมัติ ยังไม่ติ๊ก
จุดสำคัญของโหมดนี้: ไม่ต้องสร้าง Project เอง ระบบสร้างให้ทันทีที่ยืนยัน SO — แตกเป็น Task 1 อันต่อ 1 บรรทัด BOQ (6 tasks จาก 3 รายการหิน + 3 บรรทัดสรุป Overhead) พร้อม Milestone งวดชำระเงินตายตัว 30/40/30 (เงินมัดจำ / งวดกลาง / งวดส่งมอบ) ตามที่ยืนยันไว้กับลูกค้า
ขั้นตอนที่ 6 / 7 · ฝ่ายโครงการ

ติดตามงานจริงผ่าน Gantt Chart เฉพาะของ EMG-O

คลิกรูปเพื่อขยาย
ตัวอย่างจริงจากอีกโครงการ (Riverside Residence) — ระบบมี Gantt Chart เฉพาะของ EMG-O ให้ดูลำดับงานตั้งแต่สำรวจหน้างานจนถึงส่งมอบ พร้อมเส้น "Today" บอกความคืบหน้า
Gantt นี้เป็นเครื่องมือของฝ่ายโครงการเองสำหรับวางแผนลำดับงานหน้างาน แยกจาก Milestone ที่ใช้ผูกกับการวางบิล — ใช้คู่กันได้ ไม่ผูกติดกัน
ขั้นตอนที่ 6 / 7 · ฝ่ายโครงการ (ต่อ)

งานคืบหน้าถึงไหน ติ๊ก Milestone ถึงนั่น

คลิกรูปเพื่อขยาย
ติ๊กครบทั้ง 3 งวดตามความคืบหน้าจริง — ตาราง Profitability ด้านล่างอัปเดตยอด "Down Payments" ที่วางบิลไปแล้วให้เห็นสดๆ (713,790 บาท จาก 2 งวดแรก)
การติ๊ก Milestone ไม่ได้ออก Invoice ให้อัตโนมัติ — เป็นแค่การบันทึกความคืบหน้าจริงของฝ่ายโครงการ ฝ่ายบัญชีเป็นคนกดวางบิลเองอีกที (ขั้นตอนถัดไป) ตามงวดที่ตกลงกับลูกค้า
ขั้นตอนที่ 7 / 7 · ฝ่ายบัญชี

วางบิลงวดที่ 1-2 ผ่าน Down Payment Wizard มาตรฐานของ Odoo

งวดที่ 1 — เงินมัดจำ 30%
งวดที่ 2 — งวดกลาง 40%
กด "Create Invoice" บน SO แล้วเลือก "Down payment (percentage)" กรอก % ตามงวดที่ตกลงกับลูกค้า — ระบบคำนวณยอด+VAT+แท็ก Analytic Account ให้อัตโนมัติทุกครั้ง ไม่ต้องคีย์ยอดเอง
ขั้นตอนที่ 7 / 7 · ฝ่ายบัญชี (ต่อ)

งวดสุดท้าย — ระบบหักยอดที่จ่ายไปแล้วให้เองอัตโนมัติ

คลิกรูปเพื่อขยาย
INV/2026/00021 — เลือก "Regular invoice" ระบบขึ้นรายการเต็มทุกบรรทัดของ BOQ พร้อมหักงวดที่จ่ายไปแล้ว 2 ใบก่อนหน้า (-305,910 / -407,880) เหลือเรียกเก็บจริงพอดี 305,910 บาท (งวดสุดท้าย 30%)
ไม่ต้องคำนวณยอดคงเหลือเอง — เลือก Regular invoice ในรอบสุดท้าย ระบบจะเห็นเองว่ามี Down Payment ใบไหนออกไปแล้วบ้าง แล้วหักลบให้จนเหลือยอดที่ต้องเรียกเก็บจริงเท่านั้น ป้องกันการเรียกเก็บซ้ำ
